## AI 读取策略（渐进式披露）

**不要一次读全部。** 按任务需要逐层展开：

### 通用起手式（任何任务，约 3 份文件）

```
1. 00-SOP.md                              ← 工作规范
2. 05-共享上下文/项目结构速查.md          ← 知道改哪一层
3. 05-共享上下文/设计规范速查.md          ← 编码前硬门禁
```

### 按任务追加

| 任务特征 | 追加读取 |
|---------|---------|
| 涉及协议/WS/postMessage | `05-共享上下文/消息协议速查.md` |
| 涉及控制器/图形渲染 | `05-共享上下文/项目结构速查.md`「控制器层」+ `02-技术设计/前端/页面设计/` |
| 涉及业务名词 | `05-共享上下文/核心概念术语.md` |
| 涉及接口 | `05-共享上下文/技术栈速查.md`「HTTP 与网关」+ `src/service/methods/**` |
| 涉及构建/发布 | `05-共享上下文/技术栈速查.md`「构建」+ `vite.config.ts` |

## 文档双轨制

| 类型 | 含义 | 位置 | 示例 |
|------|------|------|------|
| **整体文档** | 持续积累，按域组织 | `01~03,05/` | 架构、协议、术语、规范 |
| **迭代文档** | 按迭代产出，结束后归档 | `04-迭代管理/` | 产物计划、产物汇总 |

**流转规则**：迭代中产出的设计/测试文档写入对应域目录（`01~03`），迭代目录只**记录链接**，结束时整体移入 `_archive/`。
