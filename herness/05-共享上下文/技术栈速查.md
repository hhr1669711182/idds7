## 四、环境变量（.env.*）

| 变量 | 用途 |
|------|------|
| `VITE_APP_ENV` | 应用模式标识 |
| `VITE_API_BASE_URL` | API base URL（alova `baseURL`） |
| `VITE_USE_MOCK` | `true` 时 alova 走 `@alova/mock` 适配器 |
| `VITE_GEOSERVER_URL` / `VITE_GEOSERVER_WMS_URL` | GeoServer 服务地址 |
| `VITE_AMAP_PROXY_API` | 高德代理地址 |
| `VITE_WS_URL` | WebSocket 地址（测试页可显式指定） |
| `VITE_MESSAGE_SERVICE_ORIGIN` / `VITE_MESSAGE_CLIENT` / `VITE_MESSAGE_SEAT_KEY` | 消息网关与席位 |
| `VITE_USE_WS` / `VITE_USE_POSTMESSAGE` | 消息通道开关 |
| `VITE_DISPATCH_MOCK` | dev 下是否启用本地 dispatch mock 代理 |
| `VITE_ENABLE_DYNAMIC_ROUTES` | 动态路由开关 |
| `VITE_USE_ONLINE_ICON` | 在线图标开关 |
| `VITE_PANEL_25D_URL` / `VITE_PANEL_3D_URL` | 2.5D/3D 面板 iframe 地址 |
| `VITE_PERSIST_SECRET_KEY` | 持久化加密密钥 |

> 环境读取统一走 `src/config/env.ts` 的 `appEnv`，**不要在业务代码里直接读 `import.meta.env`**。

## 五、HTTP 与网关（src/service）

**统一入口 `alovaInstance`（`src/service/alova.ts`）**：

| 机制 | 行为 |
|------|------|
| 请求拦截 | 注入 `Authorization: Bearer {token}`（来自 `useUserStore().accessToken`）+ `clientid: ids-seat-web` |
| 响应成功 | 若响应体含 `success` 字段：`success=true` → 返回 `data`；`false` → 抛 `AppError(BIZ_ERROR, message, code)` |
| HTTP 401 | 生产跳 `seat-web/login`；dev 不处理 |
| HTTP 错误 | 抛 `AppError(HTTP_ERROR)` |
| 空响应 / 非法 JSON | 抛 `AppError(INVALID_RESPONSE)` |
| 错误提示 | 默认 `ElMessage.error`，可通过 `meta.silent / showError=false` 静默 |
| mock | `VITE_USE_MOCK=true` 且存在 `service/mock/**` 时启用 `createAlovaMockAdapter` |

**用法**：优先 `src/service/methods/**` 的语义方法；底层也可 `http.get/post/put/delete`（`src/service/index.ts`）。

## 六、常用命令

```bash
pnpm dev                 # 开发（dev.local，8888）
pnpm build               # 构建应用 → dist/
pnpm build:prod          # production 模式构建
pnpm build:lib           # 库模式构建 → dist-lib/
pnpm lint                # vue-tsc --noEmit（类型门禁）
pnpm mock:server         # 本地 mock（node server/index.js）
pnpm mock:server:restart # 重启 mock
pnpm mock:server:stop    # 停止 mock
```

> 无 `pnpm test`。`tests/*.test.ts` 为遗留脚本。

## 七、后端与外部依赖（前端视角）

本仓库为纯前端，无后端代码。依赖的外部服务：

| 服务 | 接入方式 |
|------|---------|
| IDS 业务后端 | HTTP `/bff-client/api/v1/gis/**`、`/api/**`（代理到 ids-dev） |
| 消息网关 | WebSocket `VITE_WS_URL` / 登录态动态拼接（`useWebSocket`） |
| GeoServer | WMS/WFS `/geoserver/{workspace}/ows|wms`（`src/service/geoserver.ts`） |
| 高德 | 代理 `/a`（`useAmapTools`、`routeMetrics`） |
| 宿主系统 | postMessage（库模式 `hostEmitter` 或 `bindParent`） |
