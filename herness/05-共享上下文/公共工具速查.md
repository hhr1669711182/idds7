## 〇之二、消息发送：`@/controller/publish`

按 `MESSAGE_SYSTEM` 分类，`system` + `channel` 在文件内固定，调用方不传：

```ts
import { publishMapPoiPick, publishRoutePlanCancel, publishAddrPoiPick } from '@/controller/publish'

publishMapPoiPick({ lng, lat, address })   // @/controller/publish/map.ts   (system=map, ws)
publishRoutePlanCancel(routeId)            // @/controller/publish/map.ts   (system=map, ws)
publishAddrPoiPick({ lng, lat })           // @/controller/publish/host.ts  (system=host, postMessage)
```

| 文件 | 固定 system / channel | 函数 |
|------|------------------------|------|
| `map.ts` | `MAP` / `WS` | `publishRoutePlanMultiple` / `publishRoutePlanCancel` / `publishMapPoiPick` |
| `host.ts` | `HOST` / `POST_MESSAGE` | `publishAddrPoiPick` |
| `three.ts` | `THREE` / `WS` | `publishThreeBuildFormSend` |
| `dispatch.ts` / `common.ts` | 预留 | — |

返回 `boolean`（是否进入消息链路）。新增函数的完整落位流程见 [消息协议速查](消息协议速查.md)「publish 发送规范」。

> 注意与 `controller/core/io/OutputController.ts` 区分：那是**渲染层状态上报**，本目录是**业务对外发送**，语义分层不同，不要合并。

## 一、`@/utils/coordTransform` —— 坐标转换（**最高优先级复用**）

```ts
import {
  wgs84ToGcj02, gcj02ToWgs84, bd09ToGcj02, gcj02ToBd09, formatLngLat,
  type LngLat,   // type LngLat = [number, number]  ← [经度, 纬度]
} from '@/utils/coordTransform'

wgs84ToGcj02([113.93, 22.53])          // WGS84 -> GCJ-02
gcj02ToWgs84([116.403372, 39.917931])  // GCJ-02 -> WGS84
bd09ToGcj02([116.409739, 39.924269])   // BD-09 -> GCJ-02
gcj02ToBd09([116.403372, 39.917931])   // GCJ-02 -> BD-09
formatLngLat([113.93, 22.53])          // '113.930000,22.530000'（digits 默认 6）
```

**⚠️ 坐标系铁律（写错会出 638m 级事故）**

| 项 | 约定 |
|---|---|
| 业务 / 协议 / 服务层统一 | **WGS84** `[lng, lat]` |
| 高德（AMap）内部 | GCJ-02 |
| 百度（Baidu）内部 | BD-09 |
| 境外坐标 | `wgs84ToGcj02` / `gcj02ToWgs84` 自动不偏移（越界判定内置） |
| 参数形态 | **一律传 `LngLat` 元组**，不要传两个数字 |
| 往返精度 | 简化算法固有 ~0.3~0.7m（3~6e-6 度）；**不要为了"更准"再套一层纠偏**，二次纠偏就是 638m 事故 |

**历史坑**：`tests/unit/transform.spec.ts` 有「深圳往返 638m」回归用例，改动本文件必跑该测试。

## 三、`@/utils/crypto` —— 加密 / 摘要

```ts
import {
  encryptText, decryptText, encryptJson, decryptJson,
  hash, md5, sha1, sha256, hmac, pbkdf2, evpKdf,
  randomHex, randomBase64, base64UrlEncode, base64UrlDecode,
  createCrypto, createPassphraseCrypto,
} from '@/utils/crypto'
```

- 文本：`encryptText(plain, key)` / `decryptText(cipher, key)`
- 对象：`encryptJson(value, key)` / `decryptJson<T>(cipher, key)`
- 摘要：`hash(text, 'SHA256')` 或直接 `md5/sha1/sha256`
- 随机：`randomHex(bytes)` / `randomBase64(bytes)`
- 进阶：`createCrypto(options)` / `createPassphraseCrypto(...)`

> 🚫 禁止自写 AES / MD5 / SHA 实现；🚫 禁止 `Math.random()` 当加密随机源（用 `randomHex` / `randomBase64`）。

## 七、常见错误写法对照

| ❌ 错误写法 | ✅ 正确写法 |
|------------|------------|
| 手写 GCJ-02 偏移算法 | `import { wgs84ToGcj02 } from '@/utils/coordTransform'` |
| `wgs84ToGcj02(lng, lat)` 双参 | `wgs84ToGcj02([lng, lat])` 元组 |
| `${lng.toFixed(6)},${lat.toFixed(6)}` | `formatLngLat([lng, lat])` |
| 裸 `localStorage.setItem('biz_xxx')` | `storage.set('xxx', v)` / `createStorage('ns')` |
| `navigator.clipboard.writeText(t).catch(...)` 自写兜底 | `copyTextToClipboard(t, { successText: '已复制' })` |
| `crypto.subtle` / 自写 AES | `encryptText / encryptJson`（`@/utils/crypto`） |
| `new WebSocket(...)` 发消息 | `publishXxx`（`@/controller/publish`） |
| `window.addEventListener('message', ...)` 收消息 | `useMessageStore().subscribe(KEY, handler)` |
| `target instanceof Map` | `isOlMap(target)` |
| `console.log('debug')` 进业务 | `createLogger('模块名').info(...)` |
| 组件内硬编码图层名 | `LAYER_SOURCE_CONFIGS` / `@/config/layers` |
| `loader.load('/model3d/xf_fire_truck.glb')` 裸硬编码 | `assetUrls.fireTruck`（`@/const/assetPaths`） |
| 手拼 `${BASE}assets/…` 资源路径 | `withAssetBase(appEnv.assetBase, 'assets/…')` |
| `fetch(url).then(r => r.json())` 加载资源无兜底 | `loadJsonAsset<T>(url)`（`@/utils/assetUrl`，失败返回 `null`） |
| 组件内自写一份字体下拉清单 | `FONT_OPTIONS`（`@/const/assetPaths`） |
| 新增资源文件随手丢进 `public/` 不登记 | 先按 R1/R2/R3 定落位，再 `pnpm assets:manifest` 登记（文件名由模板拼出的还需登记 `KEEP_REASONS`） |
