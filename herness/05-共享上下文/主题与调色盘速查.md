# 主题与调色盘速查

> **回答什么问题**：样式里该用哪个变量？调色盘怎么切？OL 控件为什么不再写覆盖块？
> 规范见 [代码样式规范.md](代码样式规范.md)；实现见 `src/styles/**`。

---

## 一、两个正交维度

| 维度 | 属性 | 取值 | 落点 |
|------|------|------|------|
| **主题** | `document.documentElement[data-theme]` | `DAY` / `NIGHT` | `src/styles/palettes.less` |
| **调色盘** | `document.documentElement[data-palette]` | `NIGHT` / `DAY` / `OCEAN` / `EMBER` / `CUSTOM` | `src/styles/palettes.less` |

两者只改根元素属性，**业务代码零改动**即自动生效。

---

## 二、优先级（从高到低）

```
1. :root 的 inline style                          ← 自定义调色盘（CUSTOM）
2. :root[data-palette='X'][data-theme='Y']        ← 预设盘（主题感知二元组）
3. :root[data-theme='Y']                          ← 主题默认盘
4. :root 的兜底定义                                ← 交互态 token（hover/active）
```

第 4 层是**安全网**：`--hover-bg` / `--active-border` 等在 `:root` 有兜底，
即使上层没覆盖也不会取不到值 —— 避免「hover 高亮直接消失」。

---

## 三、文件职责

| 文件 | 职责 | 允许出现 |
|------|------|---------|
| `src/styles/tokens.less` | 设计常量（与主题无关） | 裸色值、间距、圆角、阴影 |
| `src/styles/palettes.less` | 调色盘变量定义 | 引用 tokens + 预设盘覆盖值 |
| `src/styles/day.less` | 白天专属的**组件级**补充 | 组件样式片段 |
| `src/styles/night.less` | 夜间专属的**组件级**补充 | 组件样式片段 |
| `src/styles/ol-controls.less` | OL 原生控件主题桥接 | `.ol-*` 选择器 |
| `src/styles/element-theme.less` | Element Plus `--el-*` 变量 | `--el-*` 定义 |
| `src/styles/index.less` | 全局入口（决定层叠顺序） | `@import` |

> `day.less` / `night.less` **不再放变量定义**，只放主题专属的组件补充。

## 四、OpenLayers 控件

OL10 的 `ol.css` 已把控件外观收敛到 **7 个官方 CSS 变量**：

```
--ol-background-color  --ol-foreground-color  --ol-accent-background-color
--ol-subtle-background-color  --ol-subtle-foreground-color
--ol-partial-background-color  --ol-brand-color
```

**做法**：在调色盘里给这 7 个变量赋值 → `ol-controls.less` 里做桥接 →
一份样式昼夜自动生效。

```less
/* palettes.less —— NIGHT 盘 */
:root[data-theme='NIGHT'] {
  --ol-background-color: #0d1929;
  --ol-foreground-color: @night-text;
  --ol-brand-color: @cyan-500;
  /* ... */
}
```

> ⚠️ **不要再写 `html[data-theme='NIGHT'] .ol-control { ... }`**：
> 那样只能覆盖一部分控件，且白天/夜间要写两遍。

## 五、底图瓦片滤镜

地图底图色感由 `context.filter` 控制，参数挂在 CSS 变量上：

| 变量 | 默认（NIGHT） | 默认（DAY） |
|------|---------------|-------------|
| `--filter-hue-rotate` | `180deg` | `0deg` |
| `--filter-invert` | `100%` | `0%` |
| `--filter-saturate` | `1600%` | `100%` |
| `--filter-brightness` | `80%` | `100%` |
| `--filter-contrast` | `90%` | `100%` |

**取值统一走工具**（禁止在业务代码手写 filter 字符串）：

```ts
import { buildFilterString, getBasemapFilter } from '@/utils/themeColor.ts'

context.filter = buildFilterString(getBasemapFilter())
```

两处使用点：`src/utils/mapTool.ts`、`src/baseComponent/OpenlayersMap/baseSource.ts`。

> ⚠️ **已知限制**：滤镜只对**栅格瓦片**（走 canvas 绘制）生效。
> 当前默认底图是 AMAP **矢量**源，不经 canvas 滤镜路径，所以夜间底图仍是浅色。
> 属独立需求，不在主题体系范围内。

## 五·二、右上角操作簇布局（位置常量）

地图页右上角是一个**视觉簇**：天气面板 → 调色盘 → 功能配置 → 主题开关（从右往左）。

| 变量 | 默认值 | 用途 |
|------|--------|------|
| `--top-actions-right` | `8px` | 簇最右侧与画面边缘的间距 |
| `--top-actions-center` | `30px` | 纵向中心线，所有元素对齐到它 |
| `--top-actions-gap` | `10px` | 簇内元素间距（移动端 6px） |
| `--top-actions-size` | `30px` | 入口按钮尺寸 |
| `--top-actions-switch-width` / `--top-actions-switch-height` | `50px` / `40px` | 主题开关占位 |
| `--weather-panel-width` | `288px` | 天气面板固定宽度（移动端 190px） |

> 这些是**布局常量**（与主题无关），定义在 `src/styles/tokens.less`，
> 经 `src/styles/palettes.less` 的 `:root` 导出为 CSS 变量，组件只 `var()` 消费。
>
> ⚠️ **不要在组件里再写 `right: 300px` 这类魔法数字**：
> 同一簇跨多个文件各写各的位置，改一个宽度就会压住另一个
> （2026-10-21 的 config 入口按钮丢失事故即由此而来）。
> 规范见 [代码样式规范.md](代码样式规范.md) §4.6。

## 六、调色盘面板（运行时调试）

入口：地图右上角调色盘图标（`src/components/map/component/paletteDrawer.vue`），El Drawer 弹出。

| 功能 | 行为 |
|------|------|
| 主题切换 | 切 `data-theme` |
| 预设盘切换 | 切 `data-palette`；预设盘是**主题感知二元组**，会自动取当前主题对应的一套值 |
| 自定义变量 | 改任意 token，自动切到 `CUSTOM` 盘；支持**单项重置**与**全部重置** |
| 底图滤镜 | 5 个滑杆；**独立于调色盘保存**，切换预设盘不会丢 |

**状态持久化**：`localStorage` key `ids-gis-web:palette`，
应用挂载时由 `useCommonStore().restorePalette()` 恢复（见 `src/lib/index.ts`）。

## 七、给 AI 的实操指引

| 你要做什么 | 怎么做 |
|-----------|--------|
| 新增组件的样式 | 只写 `var(--token)`；不要写裸色值、不要写 `data-theme` 覆盖块 |
| 需要一个主题色 | 先查本文件 Token 清单；没有就在 `palettes.less` 的 DAY/NIGHT 两个块里**同时**加 |
| 需要一个纯设计常量（圆角/间距） | 在 `tokens.less` 加 `@x`，同时在 `palettes.less` 的 `:root` 加 `--x` |
| 改 OL 控件配色 | 只改调色盘里的 `--ol-*`，不要动 `ol-controls.less` 的结构 |
| 报告「样式丢失」 | 先看 `node scripts/check-css-vars.mjs` 和 `node scripts/check-backdrop-filter.mjs` |
