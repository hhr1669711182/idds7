## 项目概况

| 项 | 值 |
|----|----|
| 项目 | ids-gis-web（IDS 智能调度系统 · GIS 前端） |
| 仓库定位 | 纯前端 GIS 工程，兼具**应用形态**与**库形态**（供宿主系统挂载） |
| 后端 | 无（依赖 ids-dev 网关 + 消息网关 + GeoServer + 高德） |
| 部署 | Docker + Nginx（见 `Dockerfile` / `nginx.conf`） |
| Git | GitLab（`gitlab.telewave.tech/ids/web/ids-gis-web`） |

## 技术状态

| 维度 | 状态 |
|------|------|
| 框架 | Vue 3.5 + TS 6.0 + Vite 8 + Pinia 3（稳定） |
| 地图/3D | OpenLayers 10 + Three 0.169 + Cesium 1.143（稳定） |
| 消息体系 | 消息中枢 + 拦截器链 + 控制层分层（已成型） |
| 类型门禁 | ⚠️ **基线不干净**：`pnpm lint`（vue-tsc）当前约 **193 个既有报错**，绝大多数是 `TS6133`（未用变量/未用导入），源于 `noUnusedLocals` / `noUnusedParameters` |
| 协议一致性 | ⚠️ **6 个事件键缺失**（见下方技术债），属真实缺陷，改动相关区域时注意 |
| 自动化测试 | ⚠️ **未配置测试框架**（无 vitest/jest，无 `test` 脚本）；`tests/**` 为遗留脚本 |

## 已知技术债 / 注意事项

| 项 | 说明 |
|----|------|
| 测试体系缺失 | 无单测框架与脚本；新增测试需先引入 runner |
| 历史拼写遗留 | `map.base.poiLoation` 等对外契约勿"修正" |
| 目录风格不统一 | `MarkDraw`（PascalCase）与多数 camelCase/kebab 并存，改动时按同目录风格 |
| 控制器聚合不全 | `DispatchController1`、`IncidentStationQuery`、`IncidentVideoOverlayController`、`vehicleManager` 未在 `business/index.ts` 聚合 |
| `useMessageStore916.ts` | 历史版本文件，确认用途后再决定去留 |
| **消息事件键缺失** | `src/controller/map/index.ts` 与 `src/controller/three/index.ts` 引用了 `MESSAGE_EVENT_KEY` 中**不存在**的键，导致 6 个 `TS2339/TS2551` 报错（详见下方「已知协议缺陷」） |
| 未用变量报错 | 约 190 个 `TS6133`，主要在 `dispatchMap.vue` / `AddressRobotController` / `GeometryController` 等，属历史遗留 |
| `.anima/` `.agnes/` `.trae/` | 工具生成目录与历史文档，非产品代码，勿误改 |
