# 核心概念术语

> 业务与系统术语对照表。理解需求文档、`docs/source/**` 与代码注释时查阅。
> 新增业务概念时追加本表（术语 → 代码符号 → 位置）。

---

## 一、系统与角色

| 术语 | 含义 | 代码符号 / 位置 |
|------|------|-----------------|
| IDS | 智能调度系统，本项目为其 GIS 前端 | — |
| 席位 / Seat | 调度席位的唯一标识，用于消息订阅 | `useUserStore().seatNumber` / `MESSAGE_SUBSCRIBE_TOPIC.SEAT` |
| 宿主系统 Host | 承载本 GIS 的主系统（如 ids-seat-web） | `MESSAGE_SYSTEM.HOST` = `host` |
| 接警员 / 调度员 | 使用本系统的人员 | — |

## 二、警情与警情画像

| 术语 | 含义 | 代码符号 / 位置 |
|------|------|-----------------|
| 警情 Alarm / Incident | 一次火灾或警情事件 | `listAlarmMethod`、`MESSAGE_SUBSCRIBE_TOPIC.ALARM_INCIDENT` |
| 警情画像 Disaster Profile | 警情的综合信息聚合（含地址、经纬度） | `ALARM_PROFILE_SYNC`、`DISASTER_PROFILE_ADDRESS_UPDATED` |
| 来电 Call | 报警电话呼入 | `MESSAGE_EVENT_KEY.INCOMING_CALL` / `onIncomingCall` |
| 来电定位 | 将来电位置在地图上落点 + 缓冲区 | `CallController.locateCall`、`map.locate.call` |
| 未结警情 | 尚未处置完毕的警情 | `getUnclosedIncidentsMethod` |
| 接听状态 | 来电是否已接听 | `alarm.call.answer_status_changed` |

## 三、调派与车辆

| 术语 | 含义 | 代码符号 / 位置 |
|------|------|-----------------|
| 调派 Dispatch | 为警情分配力量与路径的流程 | `DispatchController` / `views/dispatch` / `views/dispatch1` |
| 车辆状态 | 车辆的调度状态枚举（7 种） | `VEHICLE_STATUS_TEXT`（`const.business.type.ts`） |
| ├ 待命 DAILY_STANDBY | 车辆在位待命 | 同上 |
| ├ 已出动 DISPATCHED | 已出发 | 同上 |
| ├ 到场 ARRIVED | 已抵达现场 | 同上 |
| ├ 作战完成 OPERATION_COMPLETED | 处置完毕 | 同上 |
| ├ 归队 RETURNED | 已返回 | 同上 |
| ├ 途中返回 RETURNING | 返回途中 | 同上 |
| └ 不可用 UNAVAILABLE | 不可调度 | 同上 |
| 编队 Formation | 车辆编队信息（版本化） | `queryDispatchFormation` / `DISPATCH_FORMATION_VERSION` |
| 站点 / 队站 | 消防站、执勤点 | `IncidentStationQuery` / `DispatchStationEtaFilterData` |
| ETA 过滤 | 按预计到达时间过滤可用站点 | `dispatch.station.eta.filter` |
| 路径规划 Route Plan | 起终点间最优路径计算 | `getNavPathPlanMethod` / `dispatch.route.plan` |

## 六、消息与协议

| 术语 | 含义 | 代码符号 / 位置 |
|------|------|-----------------|
| 消息信封 Envelope | 统一消息结构 `{v,id,timestamp,system,channel,eventKey,data}` | `src/types/message.ts` |
| 事件键 Event Key | 消息的业务标识 | `MESSAGE_EVENT_KEY` |
| 通道 Channel | 传输通道：ws / postMessage / localStorage | `MESSAGE_CHANNEL` |
| 系统 System | 消息归属系统 | `MESSAGE_SYSTEM` |
| 泛订阅 | SEAT 主题的广泛订阅，二次分发到多个内部事件 | `dispatch: 'multi'` |
| 拦截器 Interceptor | 消息归一与分发的链式处理器 | `src/interceptor/**` |
| 二次分发 | 一次拦截产出多条标准化消息 | `InterceptorOutput.results[]` |
| postMessage | 跨窗口/iframe 通信 | `MESSAGE_CHANNEL.POST_MESSAGE` / `bindParent` |
