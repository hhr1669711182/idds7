# 单元测试文档示例

> 示例文档。⚠️ 本项目当前无测试框架，此处演示"引入 vitest 后的单元测试文档写法"。

## 1. 覆盖模块

`src/interceptor/unwrap.ts` — 消息体归一（纯函数，无 DOM / 无引擎依赖，最适合先覆盖）。

## 2. 用例清单

| 编号 | 场景 | 输入 | 预期 |
|------|------|------|------|
| UT-unwrap-01 | `content` 为 JSON 字符串 | `{content: '{"a":1}'}` | `content.a === 1` |
| UT-unwrap-02 | `content` 为非法 JSON | `{content: 'not json'}` | `content === null`，原样保留 |
| UT-unwrap-03 | `topics` 大小写归一 | `[{type:'custom',customType:'alarm_call'}]` | 归一为大写 |
| UT-unwrap-04 | 非对象输入 | `'string'` / `null` | 返回 `null` |
| UT-unwrap-05 | `customContent` 解析 | `{customContent:'{"x":1}'}` | `customContent.x === 1` |

## 3. 示例代码（vitest）

```ts
import { describe, it, expect } from 'vitest'
import { normalize } from '@/interceptor/unwrap'

describe('interceptor/unwrap normalize', () => {
  it('解析 JSON 字符串 content', () => {
    const r = normalize({ content: '{"a":1}' })
    expect(r?.content?.a).toBe(1)
  })

  it('非法 JSON 时 content 为 null', () => {
    const r = normalize({ content: 'not json' })
    expect(r?.content).toBeNull()
  })

  it('非对象输入返回 null', () => {
    expect(normalize('string')).toBeNull()
    expect(normalize(null)).toBeNull()
  })
})
```
