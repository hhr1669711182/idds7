# 来电定位气泡增强-技术方案

> 示例文档。演示如何按 `02-技术设计/前端/技术方案模板.md` 编写，并展示分层落点如何对应。

## 1. 文档信息
- 关联迭代：2026-W41
- 关联需求：`herness/01-产品设计/需求分析-示例.md`

## 2. 方案概述
- **背景**：见需求文档
- **目标**：来电标注呼吸动画，异常可兜底
- **范围**：仅改地图侧；不改协议

## 3. 分层落点（示例）
| # | 改动点 | 层 | 文件 | 理由 |
|---|--------|----|------|------|
| 1 | 呼吸动画参数 | 业务控制 | `src/controller/core/business/CallController.ts` | 业务语义在业务层 |
| 2 | 标注样式 | 通用控制 | `src/controller/core/generic/GeometryController.ts` | 图形能力放通用层 |
| 3 | 订阅消息 | 消息门面 | `src/controller/map/index.ts` | 经门面订阅 |
| 4 | 图标样式 | 底座 | `src/baseComponent/amap/featureStyle.ts` | 样式归样式 |

> 自检：业务控制器只调 `genericController.*`，未 import `ol`；动画参数经 protocol DTO 传入。

## 4. 涉及文件清单
### 修改
- `src/controller/core/business/CallController.ts` — `locateCall` 增加呼吸参数与去重
- `src/controller/map/index.ts` — 确保 `onIncomingCall` 订阅可取消

## 5. 关键流程
### 5.1 消息流
```
下行：服务端 → WS → interceptor(alarmCall) → useMessageStore
    → onIncomingCall(handler) → CallController.locateCall
```
