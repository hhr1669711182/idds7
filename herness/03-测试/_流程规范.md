# 测试流程

> 测试工作流：**类型门禁 + Vitest 自动化（单测 / 组件 / 集成）+ Playwright 冒烟 + 手工目视**。
> 自动化 runner 已落地（`pnpm test` / `pnpm e2e`），契约详见 `tests/harness/README.md`。

## 二、流程概览

```
技术方案完成
  │
  ├─→ 1. 类型自检      → pnpm lint（无新增报错）+ pnpm lint:baseline
  ├─→ 2. 编写测试用例  → tests/unit | tests/components（遵循 harness 四要素）
  ├─→ 3. 执行自动化    → pnpm test（必要时 pnpm test:coverage）
  ├─→ 4. E2E 冒烟     → pnpm e2e（仅在改动影响应用起动时）
  ├─→ 5. 契约核对      → 事件键/DTO/接口 与 docs/source/** 一致
  ├─→ 6. 手工目视      → 地图瓦片、视觉布局（自动化不覆盖）
  └─→ 7. 输出报告      → 03-测试/测试报告/
```

## 三、测试维度（结合本项目特点）

| 维度 | 检查项 | 方法 |
|------|--------|------|
| 类型正确性 | `strict` 报错、未用变量 | `pnpm lint` + 基线 diff |
| 分层合规 | 是否越层、通用层是否混业务 | 对照 `05-共享上下文/设计规范速查.md` |
| 协议契约 | 事件键/DTO 是否与 `docs/source/**` 一致 | `tests/unit/{unwrap,matcher}.spec.ts` + 人工比对 |
| 消息链路 | 订阅匹配四级兜底、归一规则 | `pnpm test tests/unit/matcher.spec.ts tests/unit/unwrap.spec.ts` |
| 坐标与空间 | WGS84 顺序、往返误差、百度 y 取反 | `pnpm test tests/unit/transform.spec.ts tests/unit/baidu.spec.ts`（坐标实现已统一到 `src/utils/coordTransform.ts`） |
| 配置与持久化 | 图层归一化、localStorage 契约 | `pnpm test tests/unit/mapConfig.spec.ts` |
| 面板交互 | 显隐 / 折叠 / 事件契约 / disabled 态 | `pnpm test tests/components` |
| 应用起动 | 路由能进、关键 DOM 在位、无未捕获异常 | `pnpm e2e` |
| 状态与异常 | 接口失败、断线、空数据 | 组件测试打桩 + 手工验证兜底 |
| 回归 | 是否破坏既有功能 | 存量测试全绿 + 手工回归受影响页面 |

## 四、测试类型与门禁

| 类型 | 何时做 | 门禁 |
|------|--------|------|
| 类型自检 | 每次编码后 | `pnpm lint` 无**新增**报错（用 `pnpm lint:baseline` 对比） |
| 单元 / 集成 | 每次编码后 | `pnpm test` 全绿 |
| 组件 | 改动 `src/components/**` | `pnpm test tests/components` 全绿 |
| 覆盖率 | 阶段收口 | `pnpm test:coverage` 不低于阈值（70/70/65/70） |
| E2E 冒烟 | 改动影响应用起动 / 路由 / 构建配置 | `pnpm e2e` 全绿 |
| 契约核对 | 涉及消息/接口时 | 与 `docs/source/**` 一致 |
| 手工目视 | 地图瓦片、视觉布局 | 人工确认 |

> **当前均不阻塞提交**（与 lint 基线策略一致）。`husky pre-commit` 只做提示。
> 需要卡门禁时：在 CI 中显式执行 `pnpm test` / `pnpm e2e`，用退出码拦截。

- [ ] 地图视觉改动已人工目视

## 六、测试产物管理（硬约束）

| 内容 | 位置 |
|---|---|
| 测试代码 | `tests/{unit,components,e2e,harness,fixtures}/**` |
| 覆盖率报告 | `tests/__artifacts__/coverage/` |
| E2E trace / 截图 / html 报告 | `tests/__artifacts__/e2e/` |

**`tests/__artifacts__/**` 已被 `.gitignore` 忽略**（可重新生成，不入库）。
`src/**` 内禁止出现测试文件（`vue-tsc` 的 `include` 只覆盖 `src/**/*.ts`，测试天然不污染类型门禁基线）。
