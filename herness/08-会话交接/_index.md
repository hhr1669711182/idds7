# 08-会话交接

> 跨会话交接（handoff）：把某项任务的有效上下文交给新 AI 会话，**不是**项目介绍，也**不是**聊天记录备份。
> 与其他目录分工不同：这里只保存"某任务做到哪、怎么接"；项目长期事实仍在 `05-共享上下文/`。

## 触发

| 用户输入 | 行为 |
|---|---|
| `/handoff`（或"按项目交接规范生成 handoff"） | 为当前任务生成独立快照，返回路径与接续指令后停止 |
| `/handoff resume <仓库相对路径>`（或"按项目交接规范恢复交接 <路径>"） | 读指定快照，核验后给接续摘要 |

这些是聊天指令，不是终端命令；工具若拦截未知斜杠，用普通文本等价输入。完整行为、边界与安全规则见 [_流程规范.md](_流程规范.md)；记录结构见 [交接模板.md](交接模板.md)。

## 目录约定

```
08-会话交接/
├─ _index.md          你在这里（入口与目录约定）
├─ _流程规范.md        生成 / 恢复 / 授权 / 冲突 / 安全规则
├─ 交接模板.md         唯一交接结构
└─ records/
   └─ YYYY-MM/
      └─ <任务标识>/
         └─ <YYYYMMDD-HHmmss>-<作者>-<短标识>.md
```

- 每份交接是独立快照，用 `supersedes` 指向上一份；旧快照不改写、不自动删除。
- 没有全局 `latest.md`；候选按目录发现、按任务与用户选择恢复。
- 记录默认可审阅、按需入库；本机制不自动 `git add/commit/push`。

## 与其他目录的关系

| 目录 | 关系 |
|------|------|
| `00-SOP.md` / `AGENTS.md` | 只在入口加一条路由，不堆交接历史 |
| `05-共享上下文/` | 项目长期事实与当前状态；交接仅引用，不重复 |
| `02-技术设计/` | 方案与决策依据；交接引用其路径 |
| `09-工作日志/` | 按日按人历史流水；交接含本任务接续状态，不替代日志 |
| `skills/gis-dev-workflow/` 的 `handover-doc` | 面向新人/运维的**项目全景**交接，不是本机制 |
