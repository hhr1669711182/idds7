## 二、目标与范围

- **目标**：打开「未结案警情」图层且「天气」开关 ON 时：
  1. 将未结案警情按 **5km 距离贪心聚类**（簇内多点共享一个代表点）
  2. 以每簇代表点为圆心画 **半径 2km 的蓝色虚线圈**（圈顶标注「2km」，半径不可调）
  3. 通过 `gis:env_area_weather` WFS `INTERSECTS` 查代表点所在行政区划，按 **addrlevel 逻辑**决定天气查询 adcode
  4. 用 `loadWeather(adcode)` 获取天气实况，在代表点旁挂 6 字段天气 overlay
- **入口**：`layers.vue` 工具栏「全选」右边「天气」**独立按钮**（模板注册方式），**默认 ON**；与「未结案警情」图层开关联动
- **范围**：
  - 新增 1 个业务控制器 `UnclosedWeatherRingController`（5km 聚类 + WFS adcode + 圈 `VectorLayer` + 天气 `Overlay[]` + 缓存 + 并发控制）
  - 新增 1 个协议 interface `WeatherRingProtocol`（跨层数据契约）
  - `envArea.ts` 新增 `fetchAreaWeatherByPoint`（WFS CQL INTERSECTS 反查 `gis:env_area_weather`）
  - `useLayersStore` 新增 `weatherRingEnabled`（默认 true）+ `toggleWeatherRing()`
  - `layers.vue` 新增「天气」独立按钮（`<button v-if>` 模板注册方式，非 toolbarItems 数组项）
  - `map.vue` 编排：watch [未结案警情 visible, weatherRingEnabled, alarms] → `controller.show/hide`
- **不做**：不改 `mountJRAlarmLayer` / `loadWeather` / `regeo` 代理逻辑；不做圈大小调节；不新增 WS 消息事件键

## 三、关键设计要点（视觉与数据流）

```
        ┌───────────────────────────┐
        │ 天气 · 2km                │  ← 标题：城市名（可选）
        │ 天气    多云              │
        │ 气温    30°C             │  ← 6 字段
        │ 风向    东南风            │
        │ 风力    3级              │
        │ 湿度    63%              │
        │ 降水    0mm              │
        └───────────────────────────┘
        ◄── 2km 蓝色虚线圈（半径固定，圈顶标注 "2km"）
              中心 = 警情簇代表点
```

| 要素 | 规格 |
|------|------|
| 聚合 | 5km Haversine 距离贪心聚类；簇内多点共享一个圈 + 一个 overlay |
| 圈几何 | `new Circle(fromLonLat([lng,lat]), 2000)`；半径**固定 2000m，不可调** |
| 圈样式 | `Stroke({ color: cssVar('--accent-cyan'), width: 2, lineDash: [6,4] })`；`Fill({ color: withAlpha(accent, 0.04) })` |
| 2km 标注 | 圈顶缘 `Overlay` 文本「2km」，`positioning: 'bottom-center'`，`color: accent` |
| 天气 overlay | 原生 DOM 卡片，`positioning: 'center-right'` + `offset: [12, 0]`；CSS 变量背景 |
| 面板背景 | **`var(--overlay-bg)` / `var(--border-color)` / `var(--text-primary)` / `var(--accent-cyan)`**（CSS 变量直接写在内联样式，主题切换自动生效） |
| adcode | `fetchAreaWeatherByPoint(lng, lat)` → WFS CQL `INTERSECTS(geom, SRID=4326;POINT(lng lat))` 查 `gis:env_area_weather` → 按 addrlevel 逻辑取 adcode |
| 天气 | `loadWeather(adcode)` → `WeatherLive`（10 分钟 TTL 内置缓存） |

### adcode 取值逻辑（addrlevel 判定）

`gis:env_area_weather` 视图返回 `area_id`、`addrlevel_id`、`parent_code` 等字段：

| addrlevel_id | 含义 | adcode 取值 |
|---|---|---|
| 1 | 省份 | 直接取 `area_id` |
| 2 | 地市 | 直接取 `area_id` |
| 3 | 区县 | 直接取 `area_id` |
| 4 | 街道 | 取 `parent_code`（上溯到区县级） |
| > 4 | 更细粒度 | 使用 `appEnv.mapAdcode`（env 默认 adcode） |
| 无结果 | WFS 未命中 | 使用 `appEnv.mapAdcode`（env 默认 adcode） |

> 注：直辖市对应 1-省，直辖市区县对应 2-市，以此类推（即 addrlevel 值仍为 1~4，只是语义偏移）。

## 四、触发与联动状态机

```
未结案警情图层 visible (L)  ×  天气开关 enabled (W)  →  圈+overlay 是否显示
L=ON,  W=ON   →  显示（5km 聚类后每簇画圈+overlay）
L=OFF, W=ON   →  隐藏（图层关了）
L=ON,  W=OFF  →  隐藏（开关关了）
L=OFF, W=OFF  →  隐藏

dispatch / dispatchTrack / flood 态：
  LAYER_MODE_HIDDEN_LAYER_IDS 隐藏 gis:disaster_info
  →「天气」按钮自动隐藏（功能只服务未结案警情）
```

- 「天气」开关**默认 ON**（`weatherRingEnabled = true`）
- 开关状态**跟随 `checkedIds` 同 sessionStorage 持久化**，刷新恢复
- 未结案警情图层在 `LAYER_MODE_HIDDEN_LAYER_IDS` 中被隐藏时，天气按钮自动隐藏

## 六、关键调用链

```
未结案警情图层 ON && 天气开关 ON && alarms 有数据
  └─▶ UnclosedWeatherRingController.show(alarms: WeatherRingAlarm[])
        ├─ 5km Haversine 贪心聚类 → RingCluster[]
        ├─ 对每簇（并发限 6）：
        │   ├─ addRing(repLng, repLat)          // 画 2km 蓝虚线圈 + "2km" 标注 overlay
        │   ├─ match = await fetchAreaWeatherByPoint(lng, lat)  // WFS INTERSECTS → area_id/addrlevel_id/parent_code（按坐标缓存）
        │   │    └─ adcode = resolveWeatherAdcode(match)  // addrlevel 逻辑决定 adcode
        │   │    └─ 无结果 → 使用 appEnv.mapAdcode（env 默认）
        │   ├─ weather = await loadWeather(adcode)  // 按 adcode 缓存（接口 10 分钟 TTL）
        │   │    └─ 返回 null → 该簇不挂 overlay（圈保留）
        │   └─ addWeatherOverlay(lng, lat, weather)  // 原生 DOM 卡片，CSS 变量背景
        └─ showSeq 防旧任务覆盖新结果

layers.vue「天气」独立按钮点击 → layersStore.toggleWeatherRing()
map.vue watch [disasterVisible, weatherEnabled, alarms]
  → (L && W && alarms.length) ? controller.show(alarms) : controller.hide()
```

- **并发控制**：`mapConcurrent` 限流 6 路，避免 WFS + 天气查询打爆
- **adcode 缓存**：`Map<"lng,lat" 归一(4位小数), adcode>`，警情点固定时不重复查
- **天气缓存**：`Map<adcode, WeatherLive | null>`，同区多警情簇只查一次

## 八、异常兜底

| 场景 | 兜底 |
|------|------|
| 警情无坐标（lng/lat 缺失/非法） | `toJRAlarmData` 已过滤，控制器内再校验 `Number.isFinite`，跳过不画圈 |
| `fetchAreaWeatherByPoint` 未命中 / WFS 失败 | 使用 `appEnv.mapAdcode`（env 默认 adcode）查询天气；**圈仍正常画** |
| `loadWeather` 返回 null（接口挂） | 该簇不挂 overlay，圈保留；控制台打 warn 日志 |
| 降水量缺失（`precipitation` undefined） | 显示「—」 |
| 警情点多（密集） | 5km 聚合自动减少圈数；`mapConcurrent` 限流 6 路 |
| 未结案警情图层关闭 | `controller.hide()` 隐藏全部圈+overlay，不释放（下次复用） |
| 警情数据刷新（`alarms` watch） | `show(alarms)` 全量重建圈+overlay（`clearVisuals` 先清旧） |
| 主题切换 | 圈色 `cssVar('--accent-cyan')`、overlay 用 CSS 变量内联（`var(--overlay-bg)` 等），**切换自动生效** |
| `showSeq` 过期 | 旧异步任务完成后检查 `seq !== this.showSeq` 则丢弃结果 |
