## 2. 关键调研结论（实测，非推断）

### 2.1 接口实测

对真实代理 `http://192.168.169.28:33082/api/amap/route/driving` 实测：

| strategy | 返回方案数 | 样例（dist/time） |
|----------|-----------|-------------------|
| 0~9 | 1 | 6350m/1079s |
| 10 | 3 | 6350m/1079s \| 6154m/999s \| 6062m/1048s |
| **11** | **3** | 同上 |
| 2 | 1 | 5553m/941s（距离最短） |

**结论**：`strategy=11` 稳定返回 3 个候选方案（不同 OD 实测 5 组，均返回 3 个）。

### 2.2 返回结构（实测 dump）

```
data: RoutePlan[]          // 数组，每项一个方案
  ├─ totalDistance / totalTime / trafficLights / totalFeatures
  ├─ crs
  └─ features: RouteFeature[]
       ├─ geometry.coordinates   // WGS84，可直接上图
       └─ properties
            ├─ distance    // 该 step 长度（米）
            ├─ partDesc    // 转向文案，如「沿沙河东路向南行驶456米左转调头」
            ├─ roadName    // 道路名
            └─ tmcs[]      // { distance, status, polyline(GCJ-02), lcode }
```

**关键**：响应中**没有**策略标识字段（无 `strategy`/`preference`），也**没有** `show_fields=cost` 时的额外字段（实测 `strategy=11&show_fields=cost` 仍只返回上述 7 个 key）。因此**方案档位必须前端判定**。

### 2.3 转向指引可用性

`properties.partDesc` 已含完整中文转向文案，覆盖：直行 / 左转 / 右转 / 左转调头 / 向右前方 / 靠左 / 到达目的地 —— 与截图的指引列表形态完全对应。**无需新增接口字段**。

### 2.4 档位判定能力已存在

`src/baseComponent/amap/routeAlternatives.ts` 的 `selectRouteAlternatives()` 已实现三档判定：
- `fastest` = 时长最短者
- `shortest` = 距离最短者
- `balanced` = 时长/距离双归一化打分最优者（截图的「综合最优」）

且已有标签映射 `ROUTE_PREFERENCE_LABELS`（fastest=时间最短 / shortest=距离最短 / balanced=综合推荐）与消费方 `DispatchRoutePreview.vue`。

## 4. 关键设计

### 4.1 档位判定（「躲避拥堵」怎么办）

实测 5 组 OD 的 3 方案，指标分布：

| OD | 方案0 | 方案1 | 方案2 |
|----|-------|-------|-------|
| A | 6350m/1079s | 6154m/**999s** | **6062m**/1048s |
| B | **21101m/1989s** | 21841m/2512s | 23554m/2441s |
| C | **23438m/2214s** | 24408m/2338s | 23704m/2246s |
| D | 19228m/**1633s** | 21570m/1738s | **17095m**/2275s |
| E | **19320m/1395s** | 21912m/1682s | 21870m/1735s |

- **时间最短** = `durationSeconds` 最小者 → 唯一，可靠
- **距离最短** = `distanceMeters` 最小者 → 唯一，可靠
- **躲避拥堵** = **TMC 拥堵占比最小者**（`jamRatio` 最低）。实测数据里拥堵占比普遍为 0（多段畅通），此档**可能与前两档重合**；重合时按「同一方案多标签」处理（与现有 `selectRouteAlternatives` 的 `preferences: string[]` 设计一致）。

**标签可多标**：一个方案可同时是「时间最短」和「距离最短」（如 OD B、E），截图那种单标签展示时按优先级取一个：躲避拥堵 > 时间最短 > 距离最短 > 综合最优。

### 4.2 「综合最优」的定位

截图显示 tag「综合最优」。现有实现里 `balanced` 标签文案是「综合推荐」。本次**统一改为「综合最优」**对齐截图（`ROUTE_PREFERENCE_LABELS.balanced`），涉及 `DispatchRoutePreview.vue` 同步。

### 4.3 畅通率

用户要「路况分布（畅通率）」。现有 `RouteTmcMetrics.smoothRatio` 即畅通率（0~1）。
**但要注意口径**：`summarizeTmc` 的占比分母是「有路况数据的总长度」，不是全路长度。所以 `smoothRatio` 是「已覆盖路段里的畅通占比」。展示时同时给 `coverage`（覆盖度）避免误读。

### 4.4 多方案上区分色

复用 `routeBase.ts`：
- 选中方案：`createRouteTmcFeatures` + 原色
- 备选方案：`dimRouteStyle(style)` 半透明置底（`DispatchT1.ts` 已有同款做法）
- 方向箭头：`createRouteDirectionOverlay([path])` 每方案各一个 overlay，属性带 `routePlanIndex`

新增 `SearchResultTool.showRouteOptions()` 支持一次传入多方案。

### 4.5 转向指引方向标签

`partDesc` 文本解析出转向类型，用于选方向箭头图标：

| 关键词 | 类型 | 箭头 |
|--------|------|------|
| 左转调头 / 掉头 | uturn | ↰ |
| 左转 | left | ↰ |
| 右转 | right | ↱ |
| 向右前方 / 向左前方 | slight | ↗ / ↖ |
| 靠左 / 靠右 | slight | |
| 直行 / 行驶 | straight | ↑ |
| 到达目的地 | arrive | ◎ |

解析规则：从 `partDesc` 尾部关键词匹配（高德文案「…行驶461米右转进入右转专用道」中转向词在末尾或紧跟距离后）。

## 4.6 转向指引点击定位（2026-11-10 追加）

用户追加需求：点击转向指引条目可定位到该路段。

**实现**：
- RouteStepInstruction 增 coords（该 step 的路段几何，WGS84）。高德每个 feature 的
  geometry.coordinates 即该 step 的路段，且同一方案内相邻 step 首尾相接（实测），可连续定位。
- SearchResultTool.focusRouteSegment(coords)：视野 fit 到该路段范围 + 在该路段上叠加
  强调色高亮描边（画在 focusLayer，不影响路线图层自身的分色）。
- 面板侧 ctiveStep 记录「方案 id + 指引下标」，点击后该行进入高亮态（底色 + 左侧强调条）。
  切换方案 / 重新规划 / 清空端点时重置高亮，避免高亮落在别的方案的路线上。

## 5. 界面结构（按截图）

```
┌─ 方案 1  [综合最优]              ▲ ─┐   ← 顶栏：方案序号 + tag + 折叠箭头
├─ 约33.6分钟 │ 23.80公里 │ 🚦红绿灯1个 ─┤   ← 次栏：3 个指标
├─ 距离 23.80公里  预计耗时 34分钟  红绿灯 1个 ─┤
├─ ▼ 路况分布（畅通率 82%）        ← 默认折叠，展开显示 4 条占比条
├─ ↑ 向北行驶1.3千米向左前方行驶            ← 转向指引列表
├─ ↑ 向北行驶2.8千米右转                    ← （partDesc 原文）
└─ …
```

- **多方案并列**：3 套方案以卡片形式纵向排列，首个为选中态
- **点击方案**：切换上图路线 + 切换选中态（可交互，作为「区分标识」的落点）
- **折叠箭头**：点击收起/展开该方案的次栏+指引区（与截图右上角箭头一致）
- **路况分布**：默认收起，标题行显示「畅通率 X%」，点击展开显示 畅通/缓行/拥堵/未知 四条

## 8. 异常与兜底

| 场景 | 处理 |
|------|------|
| `strategy=11` 只返回 1 个方案 | 正常展示 1 套，不报错 |
| 返回空数组 | 沿用现有「未找到可用路径」提示 |
| 货车分支 | **不变**（货车走 `drivingV2`，参数不同，本次不动） |
| `partDesc` 缺失 | 该行不显示箭头图标，只显示文案；无 `partDesc` 的行整体跳过 |
| TMC 全缺失 | 畅通率显示「暂无路况数据」，路况分布区仍可展开 |
| 多方案中某方案 geometry 异常 | 跳过该方案，不影响其余 |

| # | 项 | 说明 / 待确认 |
