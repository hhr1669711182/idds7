# 04-迭代管理

> 迭代总览与产物归档。本目录遵循「双轨制」：产物写入 `01~03` 域目录，本目录只**记录链接**。

## 迭代总览

| 迭代 | 起止 | 主题 | 状态 | 产物链接 |
|------|------|------|------|---------|
| 待创建 | | | 规划中 | |

## 使用方式

1. **迭代开始**：在 `04-迭代管理/{YYYY-WXX}/`（按 [_templates](_templates/) 建目录）填 `产物计划.md`
2. **迭代执行**：产物写入 `01-产品设计/`、`02-技术设计/前端/`、`03-测试/`，并在 `04-迭代管理/{周}/` 记录**链接**
3. **迭代结束**：`周产物汇总.md` 汇总 → 目录移入 `_archive/`

- 迭代负责人：维护总览表与产物链接
