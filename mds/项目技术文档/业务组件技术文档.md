### 2.1 地图主容器 (map/index.vue)

**文件路径：** `src/components/map/index.vue`

**功能描述：**
地图主容器组件，负责整合所有地图相关的子组件，提供统一的地图操作界面。

**组件结构：**

```vue
<template>
  <!-- 地图核心 -->
  <OpenlayersMap ref="openLayersMapRef" @setMap="getMap" />
  
  <!-- 工具栏 -->
  <tlp />        <!-- 地图工具栏 -->
  <brp />        <!-- 坐标显示 -->
  <trp />        <!-- 轨迹回放 -->
  
  <!-- 功能面板 -->
  <routePlan />           <!-- 路径规划 -->
  <topicLayerCard />      <!-- 专题图层 -->
  <baseSource />         <!-- 底图切换 -->
  
  <!-- 辅助工具 -->
  <clear />    <!-- 清除工具 -->
  <card />     <!-- 信息卡片 -->
  <bigPanel /> <!-- 大面板 -->
  <config />   <!-- 配置面板 -->
  <layers />   <!-- 图层工具栏 -->
</template>
```

**核心功能：**

| 功能 | 说明 |
|------|------|
| 地图初始化 | 通过 `OpenlayersMap` 组件初始化地图实例 |
| 图层管理 | 调用 `syncLayers` 同步勾选的图层 |
| 状态同步 | 与 Pinia Store 保持状态同步 |
| 组件通信 | 通过 `emit` 和 `ref` 实现子组件通信 |

**Props：**
无

**Emits：**
无

**核心方法：**

| 方法 | 参数 | 说明 |
|------|------|------|
| `getMap` | `map: any` | 获取地图实例并同步图层 |
| `handleLayerChange` | `action, id` | 处理图层变更 |
| `handleConfigSave` | - | 保存配置后同步图层 |

**依赖组件：**
- `OpenlayersMap` - 地图核心

### 2.4 指南针组件 (map/compass.vue)

**文件路径：** `src/components/map/compass.vue`

**功能描述：**
地图旋转控制组件，提供顺时针/逆时针旋转和复位功能。

**功能按钮：**

| 按钮 | 功能 | 旋转角度 |
|------|------|----------|
| 左侧按钮 | 逆时针旋转 | -22.5° |
| 中间按钮 | 指北针/复位 | 0° |
| 右侧按钮 | 顺时针旋转 | +22.5° |

**核心实现：**

```typescript
const handleRotate = (type?: any) => {
  const view = MapInstance.value?.getView()
  var rotation = 0
  
  if (type == "right") {
    rotation = view.getRotation() + Math.PI / 8  // 顺时针
    rotate.value += 22.5
  } else if (type == "left") {
    rotation = view.getRotation() - Math.PI / 8  // 逆时针
    rotate.value -= 22.5
  } else {
    rotate.value = rotation  // 复位
  }
  
  view.animate({
    center: view.getCenter(),
    rotation: rotation,
    easing: easeOut,  // 缓动函数
  })
}

// 监听地图旋转状态
MapInstance.value?.on("postrender", (mapEvent) => {
  const rotation = (frameState.viewState.rotation * 180) / Math.PI
  rotate.value = rotation
})
```

**依赖：**
- `useCurrentMap` - 获取地图实例
- `ol/easing` - 动画缓动函数

### 2.5 坐标显示组件 (map/brp.vue)

**文件路径：** `src/components/map/brp.vue`

**功能描述：**
实时显示鼠标位置的经纬度坐标。

**显示格式：**
```
经度：xxx.xxx°, 纬度: xxx.xxx°
```

**坐标转换：**
- 源坐标系：`EPSG:3857` (Web Mercator)
- 目标坐标系：`EPSG:4326` (WGS84)

**核心实现：**

```typescript
MapInstance?.on("pointermove", (evt) => {
  var lonLat = transform(evt.coordinate, "EPSG:3857", "EPSG:4326")
  if (lonLat && lonLat.length) {
    // 经度归一化到 [-180, 180]
    var lon = ((((lonLat[0] + 180) % 360) + 360) % 360) - 180
    coordinate.value = `经度：${lon.toFixed(3)}°, 纬度: ${lonLat[1].toFixed(3)}°`
  }
})
```

**清除逻辑：**

```typescript
const handleClear = () => {
  // 清除绘制工具
  cardStore.clearDrawTool()
  
  // 清除矢量图层要素
  const vectorLayer = MapInstance.value
    .getLayers()
    .getArray()
    .find(i => i.getClassName() == LAYER_NAMES.VECTOR_LAYER)
  
  if (vectorLayer) {
    const features = vectorLayer.getSource().getFeatures()
    features.forEach(feature => {
      vectorLayer.getSource().removeFeature(feature)
    })
  }
  
  // 清除所有 Overlay
  if (MapInstance.value.getOverlays().getArray().length > 0) {
    MapInstance.value.getOverlays().clear()
  }
}
```
