### 2.2 设计模式

#### 2.2.1 控制器模式 (Controller Pattern)

项目采用分层控制器架构，实现业务逻辑与视图解耦：

```
IOController (输入输出控制)
    ├── InputController  ──→ 接收外部消息、解析协议
    └── OutputController ──→ 发送消息给宿主应用

GenericController (通用控制)
    ├── ViewController    ──→ 视口操作、图层管理、要素拾取
    ├── GeometryController ──→ 几何运算、坐标转换
    ├── SpatialController  ──→ 空间分析、缓冲、叠加
    └── KinematicController ─→ 动态轨迹、动画控制

BusinessController (业务控制)
    ├── AlarmController   ──→ 报警业务
    ├── DispatchController ──→ 调派业务
    ├── TrackingController  ──→ 轨迹追踪
    └── CallController     ──→ 来电业务
```

#### 2.2.2 插件化架构 (Plugin System)

`mapPlugins` 提供地图功能的可插拔实现：

```typescript
// 插件接口定义
interface MapPlugin {
  name: string
  install(map: OlMap, options?: any): void
  uninstall(): void
}

// 已实现插件
useBaseMap      // 底图切换
useDraw         // 绘制工具
useOverlay      // 弹窗覆盖层
useFeatureStyle // 要素样式
useMapStatus    // 地图状态
useRoutePlan    // 路径规划
useBusUpWMS     // 业务图层
useMapUtils     // 地图工具函数
```

#### 2.2.3 组合式函数 (Composables)

使用 Vue 3 Composition API 封装可复用的逻辑：

| Composable | 功能描述 |
|------------|----------|
| `useAlarmHotspot` | 报警热点管理 |
| `useCarFeatures` | 车辆要素管理 |
| `useIncomingCallFeatures` | 来电要素管理 |
| `useAlova` | HTTP 请求封装 |
| `useResponsive` | 响应式设备检测 |
| `useWebSocket` | WebSocket 通信 |
| `useCurrentMap` | 当前地图实例获取 |

## 四、核心模块说明

### 4.1 地图核心模块 (OpenlayersMap)

**职责：** 提供 OpenLayers 地图的基础能力和核心交互。

**关键文件：**

| 文件 | 说明 |
|------|------|
| `map.vue` | 地图主组件，负责初始化地图实例、管理图层、注册交互 |
| `layers.ts` | 图层常量定义（高德底图、Google 矢量、WMS 图层） |
| `baseSource.ts` | 底图数据源工厂，支持日夜主题切换 |
| `FeatureClickQuery.ts` | 要素点击查询，处理地图要素的选择与信息展示 |
| `useMapPopups.ts` | 弹窗管理 Hook，统一管理报警、车辆、消防站等弹窗 |

**初始化流程：**

```
initMap()
  ├─ 创建底图图层 (AMAP_LAYER, GOOGLE_LAYER)
  ├─ 初始化地图实例 (new OLMap)
  ├─ 注册控件 (OverviewMap, ScaleLine, PrintDialog)
  ├─ 初始化控制器 (IOController, GenericController, BusinessController)
  ├─ 初始化管理器 (carManager, fireManager, alarmOverlayManager)
  ├─ 同步图层 (syncLayers)
  └─ 注册 FeatureClickQuery
```

### 4.2 控制器模块 (Controller)

**职责：** 实现地图功能与业务逻辑的分层解耦，通过消息协议与外部系统通信。

**协议定义：**

```typescript
// 通用协议 - GenericProtocol
interface GenericProtocol {
  'G-V01': LocateData      // 视口定位
  'G-V02': LayerToggleData  // 图层显隐
  'G-V03': ClickData        // 模拟点击
  'G-V04': Overlay3DData    // 3D 叠加
  'G-V05': FitBoundsData    // 边界适配
  'G-V06': PoiLocationData  // POI 定位
}

// 业务协议 - BusinessProtocol
interface BusinessProtocol {
  'B-A01': AlarmData        // 报警事件
  'B-D01': DispatchData     // 调派事件
  'B-T01': TrackingData     // 轨迹数据
}
```

### 4.3 插件模块 (mapPlugins)

**职责：** 提供可插拔的地图功能扩展。

**使用示例：**

```typescript
import { MapCore, useDraw, useOverlay } from '@/plugins/mapPlugins'

const mapCore = new MapCore(map)

// 安装插件
mapCore.install(useDraw, { types: ['Point', 'LineString'] })
mapCore.install(useOverlay, { popup: true })

// 卸载插件
mapCore.uninstall('useDraw')
```

### 4.4 状态管理 (Pinia Store)

**职责：** 集中管理应用的响应式状态。

| Store | 职责 |
|-------|------|
| `useLayersStore` | 管理 WMS 图层的配置、勾选状态、刷新操作 |
| `useBaseSourceStore` | 管理底图源（高德/Google）和日夜主题 |
| `useDispatchStore` | 管理调派相关状态 |
| `useCommonStore` | 通用状态（主题、用户信息等） |
