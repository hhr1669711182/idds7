# 地图图标映射控制文档

## 概述

本文档描述地图图层的图标/样式资源管理，按业务场景分为**静态资源**和**动态资源**两大类。

---

## 一、静态样式资源

静态资源不依赖运行时参数，创建后可直接复用。

### 1.1 边界线 (boundary)

| 属性 | 值 |
|------|-----|
| 样式键 | `boundary` |
| 外观 | 蓝色描边，宽度 3px |
| 颜色 | `#2563EB` |
| 使用场景 | 辖区边界、行政区划边界 |

### 1.2 遮罩层 (mask)

| 属性 | 值 |
|------|-----|
| 样式键 | `mask` |
| 外观 | 半透明黑色填充 |
| 颜色 | `rgba(0,0,0,0.12)` |
| 使用场景 | 区域外遮罩、聚焦效果 |

### 1.3 POI 点标记 (point)

| 属性 | 值 |
|------|-----|
| 样式键 | `point` |
| 图标源 | `MAP_ICON_SRC.point` (poi.png) |
| 缩放 | 1.2 |
| 锚点 | `DEFAULT_ICON_ANCHOR` [0.5, 1] |
| 使用场景 | 通用兴趣点标记 |

---

## 二、动态样式资源

动态资源依赖运行时参数，支持状态变化和实时更新。

---

### 2.1 警情类

#### 2.1.1 即时警情 (jrAlarm)

**参数：**
```typescript
{
  status: JRAlarmStatus;  // 警情状态
  scale?: number;         // 缩放比例，默认 0.9
}
```

**状态-图标映射：**

| 状态 (JRAlarmStatus) | 图标 | 说明 |
|---------------------|------|------|
| 接警 | 即时警情.png | 活跃状态 |
| 调派 | 即时警情.png | 活跃状态 |
| 途中 | 即时警情.png | 活跃状态 |
| 处置 | 即时警情.png | 活跃状态 |
| 归队 | 即时警情-灰.png | 灰显状态 |

**使用示例：**
```typescript
getStyle('jrAlarm', { status: '途中', scale: 0.9 })
```

#### 2.1.2 通用警情 (commonAlarm)

**参数：**
```typescript
{
  type: 'fire' | 'rescue' | 'society';           // 警情类型
  colorType?: 'blue' | 'red' | 'grey' | 'def';   // 颜色类型
  iconSrc?: string;                               // 自定义图标
  scale?: number;                                 // 缩放比例
}
```

**图标文件映射：**
```
./imgs/${colorType}-${type}.svg
```

| 类型 | 蓝色 (blue) | 红色 (red) | 灰色 (grey) | 默认 (def) |
|------|-------------|------------|-------------|------------|
| fire | blue-fire.svg | red-fire.svg | grey-fire.svg | def-fire.svg |
| rescue | blue-rescue.svg | red-rescue.svg | grey-rescue.svg | def-rescue.svg |
| society | blue-society.svg | red-society.svg | grey-society.svg | def-society.svg |

**使用示例：**
```typescript
getStyle('commonAlarm', { type: 'fire', colorType: 'red' })
```

#### 2.1.3 警情标记点 (alarm)

| 属性 | 值 |
|------|-----|
| 样式键 | `alarm` |
| 图标源 | `MAP_ICON_SRC.alarm` (alarm.png) |
| 缩放 | 0.9 |
| 锚点 | `DEFAULT_ICON_ANCHOR` [0.5, 1] |
| 使用场景 | 传统警情标记 |

**使用示例：**
```typescript
getStyle('alarm', { iconSrc: alarmIcon, scale: 0.9 })
```

---

### 2.2 车辆类

#### 2.2.1 车辆 (vehicle)

**参数：**
```typescript
{
  src: string;            // 车辆图标资源
  rotation: number;       // 旋转角度（弧度）
  scale?: number;         // 缩放比例，默认 0.65
  countdownText?: string; // 倒计时文本
  styleId?: string;       // 样式标识，用于缓存
}
```

**特性：**
- 锚点：`CENTER_ICON_ANCHOR` [0.5, 0.5]（居中定位）
- 旋转：`rotateWithView: true` 随地图视角旋转
- 文本：显示在图标上方，黑色半透明背景 (#111827, 86%)

**使用示例：**
```typescript
getStyle('vehicle', {
  src: CAR_ICON,
  rotation: (car.heading * Math.PI) / 180,
  scale: 0.65,
  countdownText: '03:00'
})
```

#### 2.2.2 消防车 (fireEngine)

**参数：**
```typescript
{
  iconSrc?: string;  // 自定义图标，默认 fire-engine.svg
  ...IconStyleOptions // 其他图标样式选项
}
```

**使用示例：**
```typescript
getStyle('fireEngine', { iconSrc: customFireEngineIcon, scale: 0.8 })
```

---

### 2.3 队站类

#### 2.3.1 队站 (fireStation)

**参数：**
```typescript
{
  iconSrc: string;        // 队站图标路径
  scale?: number;         // 缩放比例，默认 0.8
  deviceGoouts?: number;  // 外出设备数
  deviceTotal?: number;   // 总设备数
}
```

**特殊逻辑：**
- 仅传 `iconSrc` 和 `scale`：仅显示队站图标
- 传入 `deviceGoouts` 和 `deviceTotal`：在图标下方叠加使用率进度条

**使用率进度条规则：**

| 使用率 | 颜色 |
|--------|------|
| ≥ 70% | 红色 `#EF4444` |
| ≥ 35% | 黄色 `#F59E0B` |
| < 35% | 绿色 `#22C55E` |

**SVG 结构：**
```
┌─────────────────────────────────┐
│  3/10                    30%    │  ← 设备数量 + 百分比
│  ████████████░░░░░░░░░░░░░░░░   │  ← 进度条
└─────────────────────────────────┘
```

**使用示例：**
```typescript
// 仅图标
getStyle('fireStation', { iconSrc: FIRE_STATION_ICON, scale: 0.8 })

// 带使用率
getStyle('fireStation', {
  iconSrc: FIRE_STATION_ICON,
  scale: 0.8,
  deviceGoouts: 5,
  deviceTotal: 10
})
```

### 2.4 路径/线路类

#### 2.4.1 路径端点 (endpoint)

**参数：**
```typescript
{ type: 'start' | 'end' | 'alarm' }
```

**外观映射：**

| 类型 | 颜色 | 形状 |
|------|------|------|
| start | 绿色 `#22C55E` | 圆形带白心 |
| end | 红色 `#EF4444` | 圆形带白心 |
| alarm | 使用 alarm.png | 标准警情图标 |

**使用示例：**
```typescript
getStyle('endpoint', { type: 'start' })
```

#### 2.4.2 路况线路 (tmcLine)

**参数：**
```typescript
{
  status: AmapTmcStatus;  // 路况状态
  width?: number;         // 线宽，默认 6
}
```

**状态-颜色映射：**

| 状态 (AmapTmcStatus) | 颜色 | 含义 |
|---------------------|------|------|
| unknown | `#9CA3AF` | 未知路况 |
| smooth | `#22C55E` | 畅通 |
| slow | `#F59E0B` | 缓慢 |
| jam | `#EF4444` | 拥堵 |
| serious_jam | `#7F1D1D` | 严重拥堵 |

**使用示例：**
```typescript
getStyle('tmcLine', { status: 'jam', width: 8 })
```

## 四、锚点配置

| 常量 | 值 | 用途 |
|------|-----|------|
| `DEFAULT_ICON_ANCHOR` | `[0.5, 1]` | 默认底部中心锚点 |
| `CENTER_ICON_ANCHOR` | `[0.5, 0.5]` | 居中锚点 |

**锚点说明：** 锚点 [x, y] 表示图标定位点相对于图标尺寸的比例位置。
- `[0.5, 1]` 表示水平居中、底部对齐
- `[0.5, 0.5]` 表示完全居中

## 五、样式缓存机制

### 5.1 缓存策略

| 样式类型 | 缓存策略 |
|----------|----------|
| `vehicle` | 缓存样式实例，动态更新 rotation 和 countdownText |
| 其他样式 | 完全缓存，相同参数返回相同实例 |

### 5.2 缓存键格式

**车辆样式：**
```
vehicle:${src}:${scale}:${styleId ?? 'default'}
```

**其他样式：**
```
${key}:${JSON.stringify(params)}
```

### 5.3 缓存清理

车辆样式支持动态更新（不重新创建实例），其他样式若参数变化会创建新实例并更新缓存。

## 六、业务使用索引

| 业务场景 | 推荐样式键 | 说明 |
|----------|-----------|------|
| 辖区/行政区划边界 | `boundary` | 蓝色边界线 |
| 区域聚焦遮罩 | `mask` | 半透明黑色遮罩 |
| 传统警情标记 | `alarm` | 红色警情图标 |
| 即时警情（实时） | `jrAlarm` | 根据状态显示活跃/灰显 |
| 通用警情（多色） | `commonAlarm` | 支持 fire/rescue/society 多色 |
| 在线车辆追踪 | `vehicle` | 支持旋转、倒计时 |
| 消防车展示 | `fireEngine` | 自定义消防车图标 |
| 队站定位 | `fireStation` | 支持使用率进度条 |
| 路径规划起点/终点 | `endpoint` | start/end/alarm 三种类型 |
| 路况展示 | `tmcLine` | 五色路况等级 |
| 通用 POI | `point` | 标准点标记图标 |
