## 三、OpenLayers 原生基础工具

OpenLayers 内置了丰富的交互（Interaction）和控件（Control），无需额外安装即可使用。项目当前已使用部分，其余可按需启用。

### 3.1 已集成的原生控件

| 控件名称        | 代码引用                         | 说明           |
| ----------- | ---------------------------- | ------------ |
| OverviewMap | `map.vue`                    | 鹰眼图          |
| ScaleLine   | `map.vue`                    | 比例尺          |
| PrintDialog | `ol-ext/control/PrintDialog` | 打印（需 ol-ext） |

### 3.2 可直接启用的原生控件

以下为 OpenLayers 官方提供的控件，可直接通过 `map.addControl()` 集成：

| 控件名称            | 说明              |
| --------------- | --------------- |
| `FullScreen`    | 全屏切换            |
| `MousePosition` | 显示鼠标所在位置坐标      |
| `Rotate`        | 地图旋转按钮（复位指北）    |
| `Attribution`   | 地图版权信息          |
| `ZoomSlider`    | 滑动条缩放           |
| `ZoomToExtent`  | 一键回到全图          |
| `Language`      | 多语言切换（需 ol-ext） |

**使用示例：**

```ts
import { FullScreen, MousePosition } from 'ol/control';
import { createStringXY } from 'ol/format';

map.addControl(new FullScreen());
map.addControl(new MousePosition({
  coordinateFormat: createStringXY(6), // 保留6位小数
  projection: 'EPSG:4326',
}));
```

### 3.3 原生交互（Interaction）

OpenLayers 内置的交互类，可通过 `map.addInteraction()` 添加：

| 交互名称              | 功能               |
| ----------------- | ---------------- |
| `DragPan`         | 鼠标拖拽平移地图（默认启用）   |
| `DoubleClickZoom` | 双击缩放（默认启用）       |
| `MouseWheelZoom`  | 滚轮缩放（默认启用）       |
| `KeyboardPan`     | 键盘方向键平移（已有引用）    |
| `KeyboardZoom`    | 键盘 +/- 缩放        |
| `PinchZoom`       | 双指捏合缩放（移动端）      |
| `DragRotate`      | Shift+拖拽旋转（默认启用） |
| `DragZoom`        | Shift+拖拽框选缩放     |
| `Draw`            | 绘制几何图形（已使用）      |
| `Modify`          | 编辑已有图形（待实现）      |
| `Select`          | 要素选择             |
| `Translate`       | 要素平移             |
| `Snap`            | 捕捉到要素/网格         |

**禁用默认交互示例：**

```ts
import { defaults } from 'ol/interaction';

const map = new OLMap({
  interactions: defaults({
    doubleClickZoom: false, // 禁用双击缩放
    dragPan: false,         // 禁用拖拽平移
  }),
  // ...
});
```

## 四、工具集成建议

### 4.1 工具栏架构

建议采用统一的工具管理器来集中控制工具的激活/停用状态，避免交互冲突：

```ts
// 示例：工具管理器接口
interface IToolManager {
  activateTool(name: string): void;
  deactivateTool(name: string): void;
  getActiveTool(): string | null;
  clearAll(): void;
}
```

### 4.2 优先级建议

按以下顺序逐步完善工具链：

1. **高优先级** — 图形编辑、坐标定位、空间查询
2. **中优先级** — 缓冲分析、书签、数据导入导出
3. **低优先级** — 坡度分析、网格叠加、指南针
