## 二、消防栓组件设计

### 2.1 范围过滤场景

| 范围模式       | 输入参数                                       | 输出               | 适用场景       |
| ---------- | ------------------------------------------ | ---------------- | ---------- |
| `CIRCLE`   | `center` + `radius_meters` + `radius_unit` | 点亮圆形范围内的消防栓      | 事件定位圈周边资源  |
| `AOI`      | `aoi_geom`（aoi2、aoi3）                     | 点亮 AOI 几何范围内的消防栓 | 小区围栏/ 辖区围栏 |
| `VIEWPORT` | 无需传入                                       | 点亮视口内的消防栓        | 视口内资源浏览    |

### 2.2 资源特征过滤

按 2.3 字段过滤；接口参数对应数据库字段。无数据库字段的标注"—"。

| 过滤名称       | 数据库字段          | 接口参数                              |
| ---------- | ------------- | --------------------------------- |
| 状态过滤       | `is_enabled`  | `enable_filter.enabled=true`     |
| 文本检索       | `water_number` | `text_filter.keyword`            |
| 坐标过滤       | `geom`        | 范围加载参数（`center` + `radius_meters`） |
| 类型过滤       | `intake_form` | `fields` 字段集选择                   |
| 口径过滤       | —             | `fields` 字段集选择                   |
| 时间范围过滤     | `launched_time` | `time_filter.start` / `time_filter.end` |
| 管网过滤       | —             | `fields` 字段集选择                   |

### 2.3 组件点击详情展示

| 字段中文名    | 数据库字段          | 备注                                  |
| -------- | -------------- | ----------------------------------- |
| 消火栓编号    | `water_number` | 消防栓水源编码标识                           |
| 坐标（经纬度）  | <br />         | 存在库里，不直接展示（通过坐标值上图）                |
| 上次巡查状态   | `is_enabled`   | `true` → 可用；`false` → 不可用；WMS 样式：灰 / 红 |
| 最近巡检时间   | —              | 暂无数据，需产品侧确认                         |
| 安装类型     | `intake_form`  | 取值示例：`地上式` / `地下式`                  |
| 口径（官方名）  | —              | 暂无数据，需产品侧确认                         |
| 管网（地下支撑） | <br />         | 暂无数据，需产品侧确认                         |


### 2.4 受控交互（视图层渲染）

触发：S4 图上调派 / S5 跟踪到场 + 地图 ≥18 级；前端 → BFF → GeoServer WMS → 上图。

| 过滤条件 | 条件字段 | WMS 渲染 | 上图（前端地图） |
|----------|----------|----------|------------------|
| 范围过滤 | 圈选 / AOI / 视口 字段值 | 据范围字段渲染 | 范围内要素上图 |
| 资源特征过滤 | 启用 / 文本 / 字段 / 时间 字段值 | 据特征字段渲染 | 特征后要素上图 |
| 范围 + 资源特征 同时 | 两套都给 | 双重过滤渲染 | 双重过滤要素上图 |
| 都不指定（兜底） | 系统默认字段 | 系统默认渲染 | 默认范围要素上图 |

**约束**：与 2.1 / 2.2 / 2.5 共用同一份过滤条件 / 字段；前端不得绕开 BFF 直连 GeoServer。

**与 2.5**：2.5 走 GeoJSON 给其他系统，本节走瓦片给当前前端地图。

### 2.5 受控返回（对外提供数据）

| 过滤条件 | 条件字段 | GeoServer 空间查询 | 对外暴露（BFF 中转） |
|----------|----------|--------------------|--------------------------|
| 范围过滤 | 圈选 / AOI / 视口 | 据范围查 | → 其他系统（范围内要素） |
| 资源特征过滤 | 启用 / 文本 / 字段 / 时间 | 据特征查 | → 其他系统（特征后要素） |
| 范围 + 资源特征 同时 | 两套都给 | 双重过滤 | → 其他系统（双重过滤要素） |
| 都不指定（兜底） | 系统默认 | 系统默认查 | → 其他系统（默认范围要素） |

**约束**：与 2.1 / 2.2 / 2.4 共用同一份过滤条件 / 字段；任何系统不得绕开 BFF 直连 GeoServer。

**与 2.4**：2.4 走瓦片给当前前端，本节走 GeoJSON 给其他系统。
