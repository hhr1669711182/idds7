## 三、消防栓组件接口设计

### 3.1 范围加载参数说明

| 参数名             | 类型     |  必填 | 说明                                                      |
| --------------- | ------ | :-: | ------------------------------------------------------- |
| `center`        | array  |  否  | 圆形范围中心点经纬度数组，格式`[经度, 纬度]`，传此参数时生效                       |
| `radius_meters` | number |  否  | 圆形范围搜索半径，数值部分，单位由 `radius_unit` 指定，默认`m`，传 `center` 时必填 |
| `radius_unit`   | string |  否  | 半径单位枚举：`m`（米）、`km`（公里），默认`m`                            |
| `aoi_geom`      | string |  否  | AOI 几何范围，WKT/WKB 格式，传此参数时生效                             |
| `viewbox`       | string |  否  | VIEWPORT 视口范围，传此参数时生效                                   |

> **推断规则**：根据 scope 中实际传入的参数自动判断生效模式：
>
> - 传 `center` → `CIRCLE` 圆形范围
> - 传 `aoi_geom` → `AOI` 多边形范围
> - 传 `viewbox` → `VIEWPORT` 视口范围
> - 都不传 → 不显示消防栓

### 3.2 字段过滤参数说明

#### 状态过滤 `enable_filter`

| 参数名                | 类型      |  必填 | 说明                                        |
| ------------------ | ------- | :-: | ----------------------------------------- |
| `field`            | string  |  是  | 过滤字段名，固定为 `is_enabled`（水源是否可用）            |
| `enabled`          | boolean |  是  | 是否启用该过滤规则，`false` 表示关闭过滤，展示全部数据源          |
| `value`            | boolean |  否  | 过滤目标值，`true` 表示仅保留可用水源，`false` 表示仅保留不可用水源 |
| `include_disabled` | boolean |  否  | 是否包含停用水源，`true` 表示包含，`false` 表示仅启用水源      |

#### 文本过滤 `text_filter`

| 参数名              | 类型      |  必填 | 说明                                                              |
| ---------------- | ------- | :-: | --------------------------------------------------------------- |
| `fields`         | array   |  是  | 文本匹配的字段列表，消防栓图层支持 `water_name`（水源名称）、`address`（水源地址）            |
| `primary_field`  | string  |  是  | 主匹配字段，优先匹配该字段，消防栓图层固定为 `water_name`                             |
| `mode`           | string  |  是  | 匹配模式：`CONTAINS`（包含）、`EXACT`（精确匹配）、`PREFIX`（前缀匹配）、`SUFFIX`（后缀匹配） |
| `keyword`        | string  |  否  | 搜索关键词，为空则不生效文本过滤                                                |
| `case_sensitive` | boolean |  否  | 是否区分大小写，默认 `false`（不区分）                                         |

### 3.3 组件点击详情展示

点击消防栓图标后，在详情面板中展示该水源的基础信息。以下字段均来源于 `public.res_water` 真实表结构，暂无数据的字段标注"——"，后续如需展示应向产品/运维侧确认数据来源。

| 字段中文名       | 数据库字段          | 字段归属 | 详情面板展示                               | 备注                               |
| ----------- | -------------- | ---- | ------------------------------------ | -------------------------------- |
| 消火栓编号       | `water_number` | BASE | `water_number` 值                     | 消防栓水源编码标识                        |
| 状态          | `is_enabled`   | BASE | `is_enabled=true` → 可用；`false` → 不可用 | WMS 样式状态：灰色：false；红色：true        |
| 地址          | `address`      | BASE | `address` 值                          | 地址描述字段                           |
| 安装类型        | `intake_form`  | TYPE | `intake_form` 值                      | 取值示例：`地上式` / `地下式` / `手动` / `市政` |
| 口径          | —              | —    | ——                                   | 表中无此字段，需产品侧确认数据来源                |
| 流速          | —              | —    | ——                                   | 表中无此字段，需产品侧确认数据来源                |
| 水压          | —              | —    | ——                                   | 表中无此字段，需产品侧确认数据来源                |
| 水位（带蓄水池消火栓） | —              | —    | ——                                   | 表中无此字段，需产品侧确认数据来源                |
| 维护单位        | —              | —    | ——                                   | 表中无此字段，需产品侧确认数据来源                |
| 最近巡检时间      | —              | —    | ——                                   | 表中无此字段，需产品侧确认数据来源                |

> **字段归属说明**：`BASE` 为基础资源字段；`TYPE` 为类型字段；`STATUS` 为状态字段。详见 ods7gis 数据库 res\_water 表

## 四、接口输入模板

### 4.1 接口基础信息

| 项目   | 详情                             |
| ---- | ------------------------------ |
| 请求方式 | POST                           |
| 接口路径 | `/gis/v2/layers/resource/load` |
| 内容类型 | `application/json`             |

### 4.2 请求体模板

```json
{
  "Component_type": "组件类型",
  "scope": {
    "center": [经度, 纬度],
    "radius_meters": 搜索半径（数值）,
    "radius_unit": "m 或 km",
    "aoi_geom": "AOI几何范围（WKT/WKB格式）",
    "viewbox": "VIEWPORT视口范围"
  },
  "enable_filter": {
    "field": "is_enabled",
    "enabled": false,
    "value": true,
    "include_disabled": true
  },
  "text_filter": {
    "fields": ["water_name", "address"],
    "primary_field": "water_name",
    "mode": "CONTAINS",
    "keyword": "搜索关键词",
    "case_sensitive": false
  }
}
```

### 4.3 典型示例

#### 示例 1：S4 图上调派阶段，以警情事件中心点为圆心 1KM 范围

```json
{
  "Component_type": "env_hydrant",
  "scope": {
    "center": [116.403874, 39.914885],
    "radius_meters": 1000,
    "radius_unit": "m"
  },
  "enable_filter": {
    "field": "is_enabled",
    "enabled": true,
    "value": true,
    "include_disabled": false
  },
  "text_filter": {
    "fields": ["water_name", "address"],
    "primary_field": "water_name",
    "mode": "CONTAINS",
    "keyword": "深圳软件园一期1栋1层室内消火栓",
    "case_sensitive": false
  }
}
```

#### 示例 2：S5 跟踪到场阶段，继承 S4 范围，状态刷新

```json
{
  "Component_type": "env_hydrant",
  "scope": {
    "center": [116.403874, 39.914885],
    "radius_meters": 1000,
    "radius_unit": "m"
  },
  "enable_filter": {
    "field": "is_enabled",
    "enabled": true,

    "fields": ["water_name", "address"],
    "primary_field": "water_name",

    "keyword": "",
    "case_sensitive": false

```

#### 示例 4：不加载消防栓（S1/S2/S3 阶段）

