## 1. 优化重点总览

本系列文档相对 v1.0 进行了以下深度的优化与补充：

1. **结构去重与单一职责**：拆分原 `05-*.md` 中混杂的 ER 关系与流程图，避免"一张图讲两件事"。
2. **健壮性细化**：补充错误码与状态机，解决 v1.0 中"只看正常流，忽略异常降级"的痛点。
3. **坐标系独立成文**：明确协议层强约束 WGS84，底座适配层负责转换，避免"坐标系职责混乱"。
4. **SLA 量化**：所有核心接口补充帧率、延迟、可用性等可度量指标。
5. **Web Worker 通信契约**：高频数据（GPS 抽稀、ETA 重算）的跨线程协议标准化。

---

## 2. 通用约定

- **协议信封**：`MessageEnvelope<T>`，详见 [01-协议层与后端I O契约.md](01-协议层与后端I O契约.md)
- **坐标系**：所有协议层 JSON 默认 **WGS84 / EPSG:4326**。
- **业务 ID 规范**：`incidentId`、`carId`、`stationId` 必须在所有阶段统一。
- **图元 ID 前缀**：`marker_`、`polygon_`、`line_` 用于通用层 `GeometryController` 业务 ID 分组。
