> 版本：v1.0
> 日期：2026-07-31
> 状态：需求基线

---

## 一、组件定位

- **模块**：GIS地图模块 → 独立业务组件
- **图层**：重点单位图层（点图层，单一坐标代表单位中心点位）
- **使用场景**：S1 值守、S3 接警问询、S4 图上调派、S5 跟踪到场
- **核心能力**：接收外部控制信号，根据空间范围筛选并展示重点单位点位，同时返回重点单位的数据

## 三、外部控制接口

### 3.1 查询接口（外部 → 重点单位组件）

重点单位组件支持两种空间选择方式，由外部传入参数决定：

**方式一：画布视口（Viewport）**

```
输入：viewport bounds (westLng, southLat, eastLng, northLat)
输出：当前地图可视范围内所有重点单位
```

**方式二：小区围栏（AOI）**

```
输入：aoi_id
输出：该小区围栏范围内所有重点单位
```

### 3.2 请求格式

```
POST /gis/v2/key-units/query
```

```json
{
 "selection_mode": "VIEWPORT", // VIEWPORT | AOI

 // 方式一：视口
 "viewport": { "west": 118.78, "south": 32.03, "east": 118.80, "north": 32.05 },

 // 方式二：AOI（二选一）
 "aoi_id": "COMMUNITY-20260731-001",

 // 过滤条件（可选）
 "filter": {
 "key_unit_type": ["02医教场所", "01公众聚集"]
 },

 // 场景上下文
 "scene_context": "S1"
}
```

### 3.3 返回格式

```json
{
 "code": 0,
 "message": "success",
 "data": {
 "total": 7,
 "key_units": [
 {
 "unit_id": "ZD-001",
 "unit_code": "ZD-001",
 "unit_name": "示例市第一人民医院",
 "longitude": 118.786,
 "latitude": 32.042,
 "key_unit_type": "02医教场所",
 "industry_category": "Q",
 "person_in_charge": "李四",
 "person_in_charge_phone": "13800000002",
 "physical_address": "示例市示例区人民路 1 号",
 "admin_region": "320100",
 "loation_type": "wgs84",
 "aoi_id": "AOI-20260731-001"
 }
 ]
 }
}
```

## 四、渲染规格

### 4.1 显示规则

- **缩放级别**：S1 值守模式下 < 18级不显示，≥ 18级显示图标；S3/S4/S5 模式下地图自动缩放至 17级 显示
- **数据源**：S1 场景使用视口查询；S3/S4/S5 场景均通过微围栏 ID 反查 geom 后使用 AOI 查询
- **详情展示**：由外部动作触发，传入 unit_id 查询并展示详情
- **其他场景**：S2/S6 等场景下不展示本组件图层，画布清空

### 4.2 图标样式

- **基础色**：重点单位图层统一使用蓝色（重点单位标识色）

### 4.3 弹窗信息

外部传入 unit_id 查询并展示详情：

```
单位名称：示例市第一人民医院
重点单位类型：02医教场所
负责人：李四  13800000002
地址：示例市示例区人民路 1 号
```

## 五、用户故事场景集成

> 重点单位组件在 **S1 值守**、**S3 接警问询**、**S4 图上调派**、**S5 跟踪到场** 四个场景使用。

### 5.1 US-S1-01（值守阶段）

**触发**：S1 值守模式启动，两种触发场景：

1.  以接警员身份登录上线初始化页面
2.  由其他模式（来电弹屏/接警问询 / 调派 / 到场）返回值守模式

**动作**：

1. 监听地图缩放变化
2. 缩放 ≥ 18级时，调用视口范围查询
3. geoserver服务推送重点单位瓦片资源至前端
4. 重点单位组件展示

### 5.2 US-S3-01（接警问询阶段）

**触发**：警情接入，S3阶段微围栏已确认

**动作**：

1. 接警问询模块根据灾害地址生成微围栏，发出 CommunityFenceConfirmed 事件（含 aoi_id）
2. 重点单位组件响应事件，通过微围栏 ID 反查围栏 geom 空间信息
3. 地图组件响应事件，以灾害坐标为中心自动缩放至 17级
4. 重点单位组件以 aoi_id 为入参调用 AOI 查询，拉取围栏内重点单位
5. 返回数据，前端渲染重点单位图标

> 注：微围栏由接警问询模块根据灾害地址坐标生成。

### 5.3 US-S4-01（图上调派）

**触发**：警情已确认，进入 S4 调派阶段

**动作**：
1. 组件接收 ModeChanged → S4 事件
2. 复用 S3 阶段已建立的微围栏 ID（aoi_id，从组件状态中读取）
3. 通过微围栏 ID 反查围栏 geom 空间信息
4. 重点单位组件以 aoi_id 为入参调用 AOI 查询，拉取围栏内重点单位
5. 重点单位图标叠加显示
6. 退出 S4 时清空画布

> 设计意图：S4 阶段调度员需要快速识别警情周边的高风险重点单位（学校/医院/加油站等），辅助力量调度。

### 5.4 US-S5-01（跟踪到场）

**触发**：救援到达现场，警情地址匹配到某重点单位

**动作**：
1. 组件接收 ModeChanged → S5 事件
2. 复用 S3 阶段已建立的微围栏 ID（aoi_id，从组件状态中读取）
3. 通过微围栏 ID 反查围栏 geom 空间信息
4. 重点单位组件以 aoi_id 为入参调用 AOI 查询，拉取围栏内重点单位
5. 接收 IncidentAddressMatched 事件（含 unit_id），标记“现场目标”重点单位
6. 点击弹窗显示详情，重点突出负责人电话
7. 退出 S5 时清空画布

> 设计意图：S5 阶段指挥员需要快速联系现场负责人，争取进入权限、获取内部信息。

## 六、事件订阅

重点单位组件订阅以下外部事件：

| 事件名 | 来源 | 触发时机 | 组件动作 |
|--------|------|---------|---------|
| ModeChanged | 工作台/问询模块 | 场景切换（S1 ↔ S3 ↔ S4 ↔ S5 / 其他场景） | 清空画布，按新模式重新准备查询 |
| ZoomChanged | 地图组件 | S1 值守下缩放变化 | 缩放 < 18级清空；≥ 18级按视口查询 |
| CommunityFenceConfirmed | 接警问询模块 | S3 阶段微围栏已生成（S4/S5 复用同一 aoi_id） | 反查 geom，AOI 查询围栏内重点单位 |
| IncidentAddressMatched | 接警问询/地址解析模块 | S5 阶段警情地址匹配到重点单位 | 高亮该重点单位为“现场目标” |
| InquiryExited | 接警问询模块 | S3 阶段警情归档 / 退出问询 | 清空画布，回到 S1 值守模式 |
