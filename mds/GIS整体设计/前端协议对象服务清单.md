# 前端协议对象服务清单

> **版本**：1.1 | **日期**：2026-07-10
> **核心参考**：`GIS功能缝合.md`用户故事

---

## 一、协议分类总览

| 分类 | 前缀 | 说明 |
|------|------|------|
| 通用控制 | `map.base.*` | 地图原子能力 |
| 配置控制 | `config.*` | 系统配置 |
| 警情控制 | `alarm.*` | 警情相关 |
| 视图控制 | `layer.*` / `map.*` | 图层与视图 |
| 问询控制 | `aoi.*` | AOI/围栏相关 |
| 调派控制 | `dispatch.*` | 调度相关 |
| 跟踪控制 | `tracking.*` | 跟踪相关 |
| 场景控制 | `scene.*` | 场景切换 |
| 输出控制 | `map.view.changed` 等 | 结果输出 |

## 二、通用控制协议（map.base.*）

### 2.1 视图控制

#### map.base.locate - 视口平移缩放

```typescript
interface LocateData {
  lngLat: [number, number];  // [lng, lat]
  zoom: number;
  duration?: number;
}
```

#### map.base.layer_toggle - 图层显隐

```typescript
interface LayerToggleData {
  layerId: string;
  visible: boolean;
}
```

#### map.base.fit_bounds - 面边界定位

```typescript
interface FitBoundsData {
  geometry: GeoJSON.Polygon | GeoJSON.MultiPolygon;
  padding?: number[];      // [top, right, bottom, left], 默认留边10-15%
  duration?: number;
}
```

### 2.2 几何标绘

#### map.base.marker_add - 单点标绘

```typescript
interface MarkerAddData {
  id: string;
  lngLat: [number, number];
  iconType?: 'fire' | 'hydrant' | 'vehicle' | 'station' | 'entrance' | 'assembly';
  vehicleType?: 'main' | 'aerial' | 'foam' | 'rescue';  // 车辆类型
  isMainStation?: boolean;  // 是否主管队站车辆
  animate?: 'breathe' | 'pulse' | 'none';
}
```

#### map.base.polygon_draw - 多边形面高亮

```typescript
interface PolygonDrawData {
  id: string;
  geometry: GeoJSON.Polygon;
  style: 'primary' | 'secondary';  // 主色/次级色区分主管/支撑
  fillColor?: string;
  strokeColor?: string;
}
```

#### map.base.feature_remove - 要素批量移除

```typescript
interface FeatureRemoveData {
  featureIds: string[];
  layerIds?: string[];
}
```

### 2.3 空间分析

#### map.base.es_query - 多边形空间检索

```typescript
interface EsQueryData {
  geometry: {
    type: 'Circle' | 'Polygon';
    center?: [number, number];
    radius?: number;
    coordinates?: number[][][];
  };
  types: string[];  // ['hydrant', 'key_units', 'buildings', ...]
  limit: number;
}
```

#### map.base.route_calc - 路径规划算路

```typescript
interface RouteCalcData {
  start: [number, number];
  end: [number, number];
  strategy?: 'fastest' | 'shortest';
}
```

### 2.4 轨迹动画

#### map.base.smooth_move - 平滑移动

```typescript
interface SmoothMoveData {
  featureId: string;
  targetLngLat: [number, number];
  duration: number;  // 建议500-1000ms确保2fps+
}
```

#### map.base.track_append - 轨迹线追加

```typescript
interface TrackAppendData {
  lineId: string;
  newLngLat: [number, number];
}
```

### 3.4 调派协议（dispatch.*）

```typescript
interface MapViewChangedData {
  center: [number, number];
  zoom: number;
  bounds: {
    north: number;

  };
```

```typescript
interface MapFeaturePickData {
  incidentId?: string;
  featureType: 'vehicle' | 'alarm' | 'station' | 'resource';
  featureId: string;
  displayName: string;
  longitude: number;
  latitude: number;
}
```

### vehicle.display.state.change - 车辆状态变更

```typescript
interface VehicleDisplayStateChangeData {
  incidentId?: string;
  vehicle: {
    car_id: string;
    plate_number: string;

    selected: boolean;        // 是否选中调派
```

## 五、后端接口映射

### 5.1 HTTP API

| 前端协议 | 后端接口 | 方法 | 验收标准 |
|----------|---------|------|----------|
| `alarm.profile.sync` | 警情查询 | GET | AC-值守 |
| `dispatch.viewport.fit` | 管辖围栏 | GET | FP-4.1-4.3 |
| `dispatch.route.plan` | 路径规划 | POST | FP-4.6 |
| `dispatch.station.eta.filter` | ETA计算 | GET | FP-4.7 |
| `dispatch.route.toggle` | 调派下发 | POST | FP-4.12 |
| `tracking.vehicle.route.realtime` | ETA重算 | GET | FP-4.14 |
| `aoi.es_gisZone` | 辖区围栏 | GET | AC-问询 |

### 5.2 WebSocket 推送

| 推送类型 | 触发源 | 消费方 | 验收标准 |
|----------|--------|--------|----------|
| `incoming_call.position` | 运营商 | `map.locate.call` | AC-来电 |
| `vehicle.position` | GPS网关 | `tracking.vehicle.gps.update` | FP-4.13 |
| `vehicle.status_changed` | GPS网关 | `scene.transition` | FP-4.15 |
| `incident.created` | 警情系统 | UI组件 | AC-值守 |
| `incident.closed` | 警情系统 | UI组件 | AC-值守 |
