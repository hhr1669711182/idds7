# 消息协议数据字典

## 1. 消息信封（MessageEnvelope）

```typescript
interface MessageEnvelope {
  /** 消息唯一标识 */
  id: string;
  /** 消息事件键 */
  eventKey: MessageEventKey;
  /** 消息业务序列号（可选，用于消息关联） */
  sn?: string;
  /** 消息体（根据 eventKey 不同，body 类型不同） */
  body: any;
  /** 消息扩展信息 */
  extension?: Record<string, any>;
  /** 消息时间戳（毫秒） */
  timestamp: number;
}
```

---

## 2. 消息事件键（MessageEventKey）

```typescript
type MessageEventKey = 
  // 通用控制层
  | 'system:health'
  | 'system:heartbeat'
  | 'system:auth'
  | 'system:auth-result'
  | 'system:error'
  | 'system:push-switch'
  | 'system:config-update'
  | 'system:log-report'
  | 'system:version-check'
  | 'system:version-result'

  // 业务控制层
  | 'business:alarm-query'
  | 'business:alarm-result'
  | 'business:device-status'
  | 'business:device-data'
  | 'business:gis-update'
  | 'business:gis-query'
  | 'business:gis-result'
  | 'business:command-execute'

  // 输出控制层
  | 'output:data'
  | 'output:status'
  | 'output:subscribe'

  // WebSocket推送
  | 'push:alarm'
  | 'push:gis'
  | 'push:status'
  | 'push:command';
```
