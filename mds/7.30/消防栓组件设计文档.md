# 消防栓组件设计文档

> 版本：v1.0  
> 日期：2026-07-30  
> 状态：需求基线

---

## 一、组件定位

- **模块**：GIS地图模块 → 独立业务组件
- **图层**：消防栓图层（点图层，静态数据）
- **使用场景**：S4 图上调派、S5 跟踪到场
- **核心能力**：接收外部控制信号，根据空间范围筛选并展示消防栓点位，同时返回消防栓的数据

---

## 二、数据模型

### 2.1 消防栓主数据

| 字段 | 类型 | 说明 |
|------|------|------|
| water_id | varchar(32) | 消火栓唯一编号，主键 |
| water_number | varchar(50) | 消火栓编号（如 XF-001） |
| longitude | numeric(19,8) | 经度 |
| latitude | numeric(19,8) | 纬度 |
| hydrant_type | varchar(32) | 消防栓类型（见2.2） |
| caliber | varchar(20) | 口径（见2.3） |
| pipe_spec | varchar(20) | 管网规格（见2.4） |
| last_inspection_status | varchar(20) | 最近巡查状态（见2.5） |
| last_inspection_time | timestamp | 最近巡检时间 |


### 2.2 消防栓类型

| 类型名称 | 说明 |
|---------|------|
| 地上式 | 安装于地面，常见于北方城市 |
| 地下式 | 安装于地下，常见于南方城市 |
| 墙式 | 安装于建筑物外墙 |
| 室内 | 建筑物内部公共区域 |
| 室外 | 室外公共区域 |

### 2.3 口径

| 口径规格 | 说明 |
|---------|------|
| DN100 | 100mm，主管道标准口径 |
| DN150 | 150mm，大流量主管道 |
| DN80 | 80mm，支管道 |
| DN65 | 65mm，室内/墙式 |

### 2.4 管网规格

| 规格 | 说明 |
|------|------|
| 市政主管 | 城市市政供水主管 |
| 小区支管 | 小区内部供水支管 |

### 2.5 巡查状态

| 状态 | 说明 |
|------|------|
| 正常 | 最近巡查无异常，可正常使用 |
| 异常 | 发现问题，需要维修 |

## 三、外部控制接口

### 3.1 查询接口（外部 → 消防栓组件）

消防栓组件支持三种空间选择方式，由外部传入参数决定：

**方式一：中心点 + 半径（Circle）**

```
输入：center (longitude, latitude) + radius (米)
输出：该圆范围内所有消防栓
```

**方式二：特定 AOI 围栏（AOI）**

```
输入：aoi_id
输出：该AOI围栏范围内所有消防栓
```

**方式三：画布视口（Viewport）**

```
输入：viewport bounds (westLng, southLat, eastLng, northLat)
输出：当前地图可视范围内所有消防栓
```

### 3.2 请求格式

```
POST /gis/v2/hydrants/query
```

```json
{
  "selection_mode": "CIRCLE",  // CIRCLE | AOI | VIEWPORT
  
  // 方式一：圆形
  "center": { "longitude": 118.785, "latitude": 32.041 },
  "radius": 1000,
  
  // 方式二：AOI（二选一）
  "aoi_id": "AOI-001",
  
  // 方式三：视口（二选一）
  "viewport": { "west": 118.78, "south": 32.03, "east": 118.80, "north": 32.05 },
  
  // 过滤条件（可选）
  "filter": {
    "hydrant_type": ["地上式", "地下式"],
    "caliber": ["DN100", "DN150"],
    "status": ["正常"]
  },
  
  // 场景上下文
  "scene_context": "S4"
}
```

### 3.3 返回格式

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 42,
    "hydrants": [
      {
        "hydrant_id": "HY-001",
        "hydrant_code": "XF-001",
        "longitude": 118.786,
        "latitude": 32.042,
        "hydrant_type": "地上式",
        "caliber": "DN100",
        "pipe_spec": "市政主管",
        "last_inspection_status": "正常",
        "last_inspection_time": "2026-07-15T10:30:00Z",
        "distance_meters": 156
      }
    ]
  }
}
```

## 四、渲染规格

### 4.1 显示规则

- **缩放级别**：< 18级不显示，18级、19级显示图标
- **详情展示**：由外部动作触发，传入 hydrant_id 查询并展示详情
- **数据过滤**：S4/S5场景下，只显示巡查状态为**正常**的消防栓

### 4.2 图标样式

| 巡查状态 | 颜色 |
|---------|------|
| 正常 | 红色 |
| 异常 | 灰色 |

### 4.3 弹窗信息

外部传入 hydrant_id 查询并展示详情：

```
消火栓编号：XF-001
口径：DN100
管网规格：市政主管
巡查状态：正常
最近巡检：2026-07-15 10:30
```

## 五、用户故事场景集成

> 消防栓组件仅在 **S4 图上调派** 和 **S5 跟踪到场** 两个场景使用。

### 5.1 US4-9（调派阶段）

**触发**：进入S4调派模式（继承S3问询阶段已确认的微围栏）

**动作**：
1. 以警情事件坐标 (longitude, latitude) 为中心
2. 调用圆形区域查询，半径由**运维管理模块**配置（默认1km）
3. WebSocket 推送消防栓列表至前端

> 注：以**警情点**为中心。

### 5.2 US5-3（跟踪到场）

**触发**：首车到场，切换微观视图（缩放至≥18级）

**动作**：
1. 前端缩放级别 ≥ 18
2. 调用视口范围查询
3. 消防栓图标展示
