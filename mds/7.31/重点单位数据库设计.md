# 重点单位数据库设计

> 版本：v1.0
> 日期：2026-07-31
> 状态：需求基线
> 参照标准：GA 654-2006《消防安全重点单位信息系统数据元》、GB/T 4754-2017《国民经济行业分类》、GB/T 2260-2015《行政区划代码》

---

## 一、设计说明

- **坐标系**：WGS84（SRID=4326）
- **存储方式**：PostgreSQL + PostGIS
- **只描述业务实体及字段，不含技术实现细节**
- **基准字段映射**：
  - 单位名称 → `key_unit.unit_name`
  - 负责人及联系电话 → `key_unit.person_in_charge + person_in_charge_phone`
  - 重点单位类型 → `key_unit.key_unit_type`（字典外键）
  - 经纬度 → `key_unit.longitude / latitude`
  - 物理地址 → `key_unit.physical_address`

## 三、实体详情

### 3.1 重点单位（key_unit）

**说明**：重点单位主数据，记录每个消防安全重点单位的基础信息、位置信息与责任主体信息。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| unit_id | varchar(32) | PK | 重点单位ID |
| unit_code | varchar(50) | Unique | 重点单位编号（系统内部统一编码） |
| unit_name | varchar(200) | Not Null | 单位名称 |
| credit_code | varchar(18) | Unique | 统一社会信用代码（GB 32100-2015） |
| key_unit_type | varchar(16) | FK | 重点单位类型（关联 `key_unit_type.type_code`） |
| industry_category | varchar(4) | FK | 行业类别（关联 `industry_category.code`，GB/T 4754） |
| person_in_charge | varchar(100) | Not Null | 重点单位负责人（作为调度主要联系人） |
| person_in_charge_phone | varchar(20) | Not Null | 负责人联系电话 |
| longitude | numeric(19,8) | Not Null | 经度 |
| latitude | numeric(19,8) | Not Null | 纬度 |
| physical_address | varchar(500) | Not Null | 物理地址 |
| admin_region | varchar(12) | FK | 行政区划代码（关联 `administrative_region.code`，至县/区一级） |
| loation_type | varchar(20) | Default 'wgs84' | 坐标类型（wgs84 / gc / bd / gd） |
| is_deleted | boolean | Default false | 软删除标记 |
| created_at | timestamp | Not Null | 创建时间 |
| updated_at | timestamp | Not Null | 最后更新时间 |

> **国标对位说明**：
> - 本台账面向调度员使用，仅保留"重点单位负责人"一个联系人字段（`person_in_charge` / `person_in_charge_phone`）。法定代表人、消防安全责任人、消防安全管理人身份证号等企业治理/合规字段不进入本台账，必要时可联调公安部 61 号令相关业务系统查询。

### 3.2 重点单位类型（key_unit_type）

**说明**：依据 GA 654-2006 与公安部 61 号令第十三条梳理的重点单位类别字典。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| type_code | varchar(16) | PK | 类型编码 |
| type_name | varchar(100) | Not Null | 类型名称 |

**数据内容**：

| type_code | type_name |
|-----------|-----------|
| 01公众聚集 | 公众聚集场所（商场/市场/宾馆/饭店/影剧院/娱乐等） |
| 02医教场所 | 医院/养老院/寄宿制学校/托儿所/幼儿园 |
| 03国家机关 | 国家机关 |
| 04广电通信 | 广播电台/电视台/邮政/通信枢纽 |
| 05客运交通 | 客运站/码头/民用机场 |
| 06文博档案 | 图书馆/展览馆/博物馆/档案馆/文物保护单位 |
| 07能源电力 | 发电厂/变电站/电网经营企业 |
| 08易燃易爆 | 易燃易爆化学物品生产/充装/储存/供应/销售单位 |
| 09劳动密集 | 服装/制鞋等劳动密集型生产加工企业 |
| 10科研单位 | 重要的科研单位 |
| 99其他 | 其他火灾危险性大或可能造成重大损失的单位 |

---

### 3.3 行业类别（industry_category）

**说明**：GB/T 4754-2017 国民经济行业分类门类字典，使用门类代码。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| code | varchar(4) | PK | 门类代码（A–T） |
| name | varchar(100) | Not Null | 门类名称 |

**数据内容（节选）**：

| code | name |
|------|------|
| A | 农、林、牧、渔业 |
| B | 采矿业 |
| C | 制造业 |
| D | 电力、热力、燃气及水生产和供应业 |
| E | 建筑业 |
| F | 批发和零售业 |
| G | 交通运输、仓储和邮政业 |
| H | 住宿和餐饮业 |
| I | 信息传输、软件和信息技术服务业 |
| J | 金融业 |
| K | 房地产业 |
| L | 租赁和商务服务业 |
| M | 科学研究和技术服务业 |
| N | 水利、环境和公共设施管理业 |
| O | 居民服务、修理和其他服务业 |
| P | 教育 |
| Q | 卫生和社会工作 |
| R | 文化、体育和娱乐业 |
| S | 公共管理、社会保障和社会组织 |
| T | 国际组织 |

---

### 3.4 行政区划（administrative_region）

**说明**：GB/T 2260-2015 行政区划代码字典，最小到县/区一级。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| code | varchar(12) | PK | 行政区划代码（6位省/市/县 + 可选6位街道/乡/镇） |
| name | varchar(100) | Not Null | 行政区名称 |
| level | varchar(20) | — | 级别（省/市/区县/街道乡镇） |

## 四、ER图

```
key_unit_type (类型字典)                industry_category (行业字典)          administrative_region (行政区划字典)
├── type_code PK                        ├── code PK                            ├── code PK
└── type_name                           └── name                               └── name

                                                            │
                                                            │ FK
                                                            ▼
                                                        key_unit (重点单位主数据)
                                                        ├── unit_id PK
                                                        ├── unit_code UK
                                                        ├── unit_name / credit_code
                                                        ├── key_unit_type   FK → key_unit_type.type_code
                                                        ├── industry_category FK → industry_category.code
                                                        ├── person_in_charge / person_in_charge_phone
                                                        ├── longitude / latitude
                                                        ├── physical_address
                                                        ├── admin_region FK → administrative_region.code
                                                        ├── loation_type
                                                        ├── is_deleted
                                                        └── created_at / updated_at
```
