# 重点单位数据库设计

> 版本：v1.0（稳定基线）
> 日期：2026-07-31
> 状态：需求基线（稳定版）
> 备注：基于 v1.3 全面评审后的精简稳定版本；上一迭代（v1.0–v1.3）内容已合并、新增、重构至此版本。可作为后续 v1.x 系列的参考基线。

---

## 一、设计说明

- **坐标系**：WGS84（SRID=4326，强制）
- **空间几何**：PostGIS GEOMETRY Point 类型，SRID 4326
- **空间索引**：`geom` 字段强制 GIST 索引
- **文本索引**：`name_pinyin`、`name_en` GIN（pg_trgm）索引
- **审计**：所有写操作（INSERT / UPDATE / DELETE / `incident_engagement` 状态变更）记录 `key_unit_audit`
- **存储方式**：PostgreSQL + PostGIS
- **编码原则**：所有字典字段均使用纯数字编码，中文字段仅用于显示
- **多语言**：字典类型名称支持中文 + 英文（`type_name` + `type_name_en`），运行时按客户端语言切换

## 三、实体详情

### 3.1 重点单位（key_unit）

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| unit_id | varchar(32) | PK | 重点单位ID |
| unit_code | varchar(50) | Unique | 重点单位编号（系统内部统一编码） |
| unit_name | varchar(200) | Not Null | 单位名称 |
| name_pinyin | varchar(500) | — | 单位名称拼音（首字母 + 全拼，空格分隔，用于模糊检索） |
| name_en | varchar(200) | — | 单位名称英文（用于英文检索） |
| credit_code | varchar(18) | Unique | 统一社会信用代码（GB 32100-2015） |
| key_unit_type | varchar(2) | FK, Not Null | 重点单位类型编码（关联 `key_unit_type.type_code`） |
| industry_category | varchar(4) | FK | 行业类别编码（关联 `industry_category.code`，GB/T 4754） |
| status | varchar(2) | Not Null, Default '01' | 业务状态（01在用 / 02停用） |
| incident_engagement | varchar(2) | Not Null, Default '00' | 现场参与状态（00空闲 / 01到场中 / 02离场归档） |
| person_in_charge | varchar(100) | Not Null | 重点单位负责人（作为调度主要联系人） |
| person_in_charge_phone | varchar(20) | Not Null | 负责人联系电话 |
| longitude | numeric(19,8) | Not Null | 经度（中心点） |
| latitude | numeric(19,8) | Not Null | 纬度（中心点） |
| geom | geometry(Point, 4326) | Not Null | 空间几何点（与 longitude/latitude 同步，强制 GIST 索引） |
| physical_address | varchar(500) | Not Null | 物理地址 |
| admin_region | varchar(12) | FK | 行政区划代码（关联 `administrative_region.code`，至县/区一级） |
| location_type | varchar(20) | Default 'wgs84' | 坐标类型（wgs84 / gc / bd / gd） |
| is_deleted | boolean | Default false | 软删除标记 |
| created_at | timestamp | Not Null | 创建时间 |
| updated_at | timestamp | Not Null | 最后更新时间 |

**字段必填与合法性约束**：
- 必有唯一的坐标点（`longitude` / `latitude` / `geom` 一致）
- 必有 `person_in_charge` 和 `person_in_charge_phone`
- `key_unit_type` 必须在 `key_unit_type` 字典内
- `status` 必须在合法枚举内
- `incident_engagement` 状态变化必须由受控事件触发（不允许直接 UPDATE）

### 3.3 行业类别（industry_category）

依据 GB/T 4754-2017 国民经济行业分类门类字典，门类代码 A–T。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| code | varchar(4) | PK | 门类代码 |
| name | varchar(100) | Not Null | 门类名称 |

### 3.4 行政区划（administrative_region）

依据 GB/T 2260-2015 行政区划代码字典，最小到县/区一级。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| code | varchar(12) | PK | 行政区划代码（6位省/市/县 + 可选6位街道/乡/镇） |
| name | varchar(100) | Not Null | 行政区名称 |
| level | varchar(20) | — | 级别（省/市/区县/街道乡镇） |

### 3.6 重点单位审计（key_unit_audit）

**说明**：所有写操作（INSERT / UPDATE / DELETE / `incident_engagement` 状态变更）记录审计。审计表只 INSERT，不 UPDATE / DELETE。保留期 ≥ 5 年（公安部 61 号令）。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| audit_id | bigserial | PK | 审计记录 ID |
| unit_id | varchar(32) | FK, Not Null | 重点单位 ID |
| operation | varchar(32) | Not Null | 操作类型（INSERT / UPDATE / DELETE / MARK_ENGAGEMENT_01 / 02 / RESET_ENGAGEMENT_00） |
| operator_id | varchar(32) | — | 操作人 ID |
| operator_name | varchar(100) | — | 操作人姓名 |
| operation_time | timestamp | Not Null, Default CURRENT_TIMESTAMP | 操作时间 |
| reason | text | — | 变更原因 |
| before_value | jsonb | — | 变更前记录（INSERT 为 null） |
| after_value | jsonb | — | 变更后记录（DELETE 为 null） |
| changed_fields | varchar(2000) | — | 变更字段（逗号分隔，UPDATE 用） |
| trace_id | varchar(64) | — | 链路追踪 ID |
| incident_id | varchar(32) | — | 关联警情 ID（engagement 变更用） |

## 六、字段索引规范

| 字段 | 索引类型 | 强制 | 用途 |
|------|---------|------|------|
| `key_unit.geom` | GIST | **必需** | 空间查询 |
| `key_unit.name_pinyin` | GIN（pg_trgm） | 必需 | 拼音模糊检索 |
| `key_unit.name_en` | GIN（pg_trgm） | 必需 | 英文模糊检索 |
| `key_unit.status` / `incident_engagement` / `key_unit_type` / `admin_region` | B-tree | 必需 | 状态过滤 |
| `key_unit.unit_id` | PK | 必需 | 主键 |
| `key_unit.unit_code` / `credit_code` | UNIQUE | 必需 | 业务唯一性 |
| `key_unit_audit.(unit_id, operation_time DESC)` | B-tree | 必需 | 审计历史查询 |
| `key_unit_audit.trace_id` | B-tree | 必需 | 链路追踪 |
| `key_unit_audit.(operation, operation_time DESC)` | B-tree | 必需 | 按操作类型筛选 |
| `key_unit_audit.incident_id` | B-tree | 必需 | 警情审计关联 |
