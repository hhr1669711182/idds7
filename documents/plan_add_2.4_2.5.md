# 计划：在 GIS图层设计文档(1) 中新增 2.4 受控交互 / 2.5 受控返回

## 一、Summary

在 `d:\work\telewave\ids\ids-gis-web\mds\7.29\GIS图层设计文档(1)(1).md` 的"二、消防栓组件设计"中，新增两个章节：
- **2.4 受控交互（输入）**：前端将范围过滤 + 资源特征过滤参数传入 BFF，触发图层数据查询
- **2.5 受控返回（输出）**：GeoServer 查询后返回的结果数据，支持 WMS 上图或直接暴露数据

## 二、Current State

当前文档二、消防栓组件设计已有：
- 2.1 范围过滤场景（CIRCLE / AOI / VIEWPORT）
- 2.2 资源特征过滤（状态过滤 / 文本检索 / 类型过滤 / 口径过滤 / 时间范围过滤 / 管网过滤）
- 2.3 组件点击详情展示（字段列表）

缺少：
- 受控输入链路（谁来触发、传什么参数、触发后做什么）
- 受控输出链路（GeoServer 返回什么数据、走什么通道、上图还是直接暴露）

## 三、Proposed Changes

### 3.1 新增 2.4 受控交互

插入到 2.3 之后，描述：

**谁触发**：`前端` 触发
**触发条件**：`S4 图上调派` / `S5 跟踪到场` 阶段，地图 ≥18 级
**传入参数**：合并 2.1 范围过滤 + 2.2 资源特征过滤
**触发后动作**：BFF 返回 render_plan，前端直连 GeoServer 执行 WMS/WFS

表格结构：

| 交互阶段 | 触发方 | 触发条件 | 传入参数 | 触发后动作 |
|---------|------|---------|---------|---------|
| 受控加载 | 前端 | S4/S5 ≥18级 | 范围过滤 + 资源特征过滤参数 | BFF 返回 render_plan，前端直连 GeoServer |

### 3.2 新增 2.5 受控返回

插入到 2.4 之后，描述：

**返回通道**：`GeoServer WMS` 或 `GeoServer WFS` 或 `直传数据`
**返回结果**：上图数据 或 结构化数据

| 返回模式 | 数据来源 | 返回内容 | 适用场景 |
|--------|--------|---------|---------|
| WMS 上图 | GeoServer WMS | 瓦片渲染图层 | 大量资源上图展示 |
| WFS 查询 | GeoServer WFS | 要素 GeoJSON | 少量数据/表单/详情 |
| 直传数据 | BFF | 结构化 JSON | 无 GeoServer 场景 |

## 四、Assumptions & Decisions

- 假设受控交互触发方为前端（与 BFF 输入输出设计文档一致）
- 假设返回数据来源为 GeoServer（BFF 不代理地图数据）
- 假设输出模式为两种：WMS 上图 / WFS 查询 + 直传
- 不涉及 WebSocket 推送，本次只描述请求-响应链路
- 不新增接口路径，沿用现有 `/gis/v2/layers/resource/load`

## 五、Verification

- 新增 2.4 / 2.5 后文档结构完整覆盖：场景 → 范围 → 过滤 → 详情 → 交互 → 返回
- 2.2 资源特征过滤中的接口参数与 2.4 传入参数一致
- 无接口路径变更，不影响现有接口模板
