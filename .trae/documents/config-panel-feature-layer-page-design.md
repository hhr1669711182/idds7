# config.vue「功能配置 / 图层配置」面板 - 页面设计说明（Desktop First）

## 1) Layout（布局）
- 总体：右侧抽屉（Drawer）或侧边面板（Side Panel）形态，固定宽度优先（建议 420–520px），内容区纵向滚动。
- 布局体系：
  - 外层使用 Flexbox：`header (fixed)` + `content (flex:1; overflow:auto)` + `footer (fixed)`。
  - 列表区域使用“树形缩进 + 行内栅格”组合：左侧为层级标题/折叠箭头，右侧为开关与排序控件。
- 间距：
  - 行高建议 36–40px；层级缩进每级 16px；分组之间 8–12px 分隔。
- 响应式：
  - Desktop first；当视口宽度较窄时（例如 < 1024px），抽屉宽度自适应为 `min(90vw, 520px)`；按钮文字可缩短但不隐藏“保存/取消”。

## 2) Meta Information（页面级元信息）
- Title：地图配置
- Description：管理功能与图层的分组、分类顺序及显示开关
- Open Graph：
  - `og:title=地图配置`
  - `og:description=管理功能与图层的分组、分类顺序及显示开关`

> 若该面板非独立路由页面，上述元信息由宿主页面统一维护；此处仅作为产品语义定义。

## 3) Global Styles（全局样式/设计令牌）
- 背景：面板背景 `#FFFFFF`；内容区底色可用轻灰 `#F7F8FA`（可选）。
- 边框/分割线：`#E5E7EB`，1px。
- 字体：
  - 标题 16–18px / semibold；列表主文字 14px；辅助信息 12px。
- 主题色（强调/主按钮）：沿用项目现有主题色（若无明示，建议蓝系）。
- 按钮：
  - Primary：保存；hover 加深；disabled 置灰并禁止点击。
  - Secondary：取消；hover 轻微底色。
- 开关：
  - On/Off 清晰可辨；当上层为“部分开”时，以半选/横杠态展示（视觉提示不等价于可提交值）。

## 4) Page Structure（结构）
面板由 3 个固定区组成：
1. Header：标题 + 关闭
2. Content：页签 + 树形配置列表
3. Footer：取消/保存

## 5) Sections & Components（分区与组件说明）

### 5.1 Header 区
- 标题：`地图配置`（或与产品一致的命名）。
- 关闭按钮：点击等价于“取消并关闭”还是“直接关闭”由宿主定义；建议：
  - 若存在未保存更改（isDirty=true），关闭时触发与取消一致的回滚逻辑或提示（提示是否需要由产品决定；本需求不强制弹窗）。

### 5.2 Tabs（页签区）
- 两个页签：
  - 功能配置
  - 图层配置
- 交互：
  - 点击切换，保留当前 draft（不自动保存、不自动回滚）。
  - 页签上可选显示“未保存”提示点（当该页签对应内容发生修改）。

### 5.3 树形配置列表（核心区）
树结构层级：
- 第 1 级：分组（Group）
- 第 2 级：大类（Category）
- 第 3 级：细类（SubCategory）

#### 5.3.1 列表行通用组成
每一行从左到右建议包含：
- 折叠/展开图标（有子节点时显示）
- 名称文本（分组可编辑）
- 排序控件（同级顺序）：
  - 建议提供“上移/下移”两个按钮（或拖拽把手）；排序后即时更新 UI。
- 显示开关（Switch）：
  - 分组/大类/细类都具备。
  - 上层支持“三态显示”（on/off/partial），其中 partial 为 UI 状态，不直接写入持久化字段。

#### 5.3.2 分组（Group）行
- 名称：
  - 支持“点击进入编辑态”（input），回车或失焦提交到 draft。
  - 校验：非空（为空则恢复原值或给出输入错误态；不强制弹出提示框）。
- 开关：切换时联动下级所有节点。

#### 5.3.3 大类（Category）行
- 名称只读展示（若未来要编辑，需另立需求）。
- 开关：切换时联动其下所有细类。

#### 5.3.4 细类（SubCategory）行
- 名称只读展示。
- 开关：仅影响自身；变更后触发向上回算。

#### 5.3.5 展开/收起
- 默认展开策略：
  - 可默认展开所有分组，或记忆上次展开状态（若要记忆需另立需求；此处默认不持久化，仅面板打开期间保留）。

### 5.4 Footer（底部操作区）
- 左侧：取消（Secondary）
- 右侧：保存（Primary）
- 状态：
  - `isDirty=false`：保存按钮 disabled；取消可作为“关闭”或“回滚并关闭”（由宿主统一处理）。
  - `isDirty=true`：保存按钮 enabled。

## 6) 关键交互与事件（与技术契约一致）
- 保存：点击后触发 `onSave(payload)`，payload 包含“功能配置 + 图层配置”的完整结构。
- 取消：点击后触发 `onCancel()`，并回滚到打开面板时的快照。
- 排序：任何上移/下移/拖拽完成后，立即刷新同级 `order`，并置 `isDirty=true`。
- 开关联动：任何 visible 变更后，执行“向下联动 + 向上回算”，并置 `isDirty=true`。
