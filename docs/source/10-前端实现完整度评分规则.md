### 10-前端实现完整度评分规则

> 版本: v1.0  
> 日期: 2026-07-24  
> 范围: GIS 前端模块整体实现质量评分（100 分制）

---

## 1. 评审机制

GIS 前端模块评审以 **5 个核心场景的运行时输出**（值守 / 来电 / 问询 / 调派 / 跟踪）为评价对象，围绕以下五个维度：

| 评审维度 | 量化指标 | 关键验收点 | 评判条（判断标准） |
| -------- | -------- | ---------- | ------------------ |
| 渲染性能 | 帧率 ≥ 30fps（P95） | 5 场景帧率达标 | ① 5 场景全部 ≥ 30fps ② 跟踪场景 ≥ 30fps |
| 业务响应 | 端到端延迟 ≤ 500ms | 警情触发到画面更新 | ① 来电弹屏 ≤ 500ms ② 调派路径下发 ≤ 1s |
| 算路效率 | 算路耗时 ≤ 1s（P95） | 调派算路性能 | ① P95 ≤ 1s ② 失败降级不阻塞主流程 |
| 资源回收 | 业务 ID 精准回收 100% | 关闭/离场不残留 | ① 警情关闭图元清空 ② 车辆离场不残留 |
| 架构合规 | 五层架构无越层 100% | 调用链符合架构 | ① UI 不直接调通用控制层 ② 业务控制层不调用渲染层 API |

## 2. 评分公式（100 分制）

本评分用于衡量 **GIS 前端模块整体实现质量**，非个人绩效评分。评分周期建议为每迭代/每发版统计。

### 2.1 评分维度与权重

| 维度 | 权重 | 满分 | 说明 |
| ---- | ---- | ---- | ---- |
| 渲染性能 | 25% | 25 分 | 5 场景帧率 |
| 业务响应 | 25% | 25 分 | 端到端延迟 |
| 算路效率 | 15% | 15 分 | 调派路径计算 |
| 资源回收 | 15% | 15 分 | 业务 ID 精准释放 |
| 架构合规 | 20% | 20 分 | 五层架构符合度 |

### 2.2 各维度评分细则

#### 2.2.1 渲染性能（25 分）

基于 5 个核心场景的 P95 帧率（FPS）计算。

```
渲染性能得分 = 25 × (达标场景数 / 5)
```

| 指标 | 满分条件 | 扣分规则 |
| ---- | -------- | -------- |
| 值守帧率 | ≥ 30fps 得满分 | 每低 5fps 扣 1 分 |
| 来电弹屏帧率 | ≥ 30fps 得满分 | 每低 5fps 扣 1 分 |
| 问询研判帧率 | ≥ 30fps 得满分 | 每低 5fps 扣 1 分 |
| 图上调派帧率 | ≥ 30fps 得满分 | 每低 5fps 扣 1 分 |
| 跟踪到场帧率 | ≥ 30fps 得满分 | 每低 5fps 扣 1 分 |

> 注：跟踪场景要求 ≥ 30fps 而非更高，是因为我们按节流（30fps）渲染 + 事件驱动状态机（不每帧更新状态机）。

#### 2.2.2 业务响应（25 分）

基于关键操作端到端延迟计算。

```
业务响应得分 = 25 × (达标项数 / 总检查项)
```

| 指标 | 满分条件 | 扣分规则 |
| ---- | -------- | -------- |
| 来电触发到弹屏 | ≤ 500ms 得满分 | 每超出 100ms 扣 2 分 |
| 调派指令到路径下发 | ≤ 1s 得满分 | 每超出 200ms 扣 2 分 |
| 警情订阅到画面更新 | ≤ 800ms 得满分 | 每超出 100ms 扣 1.5 分 |
| 视野切换响应 | ≤ 300ms 得满分 | 每超出 50ms 扣 1 分 |
| 状态机迁移指令响应 | ≤ 200ms 得满分 | 每超出 50ms 扣 1 分 |

#### 2.2.3 算路效率（15 分）

基于调派路径算路耗时与成功率计算。

```
算路得分 = 15 × 算路成功率 × min(1, 1s / P95 耗时)
```

| 指标 | 满分条件 | 扣分规则 |
| ---- | -------- | -------- |
| 算路耗时 P95 | ≤ 1s 得满分 | 每超出 200ms 扣 1 分 |
| 算路成功率 | ≥ 99% 得满分 | 每低 0.5% 扣 1 分 |
| 算路失败降级 | 100% 降级不阻塞 | 失败阻塞主流程扣 5 分 |

#### 2.2.4 资源回收（15 分）

基于业务 ID 精准释放率与残留检测。

```
资源回收得分 = 15 × 精准释放率
```

| 指标 | 满分条件 | 扣分规则 |
| ---- | -------- | -------- |
| 警情关闭图元清空 | 100% 得满分 | 每残留 1 个图元扣 0.5 分 |
| 车辆离场图元清空 | 100% 得满分 | 每残留 1 个图元扣 0.5 分 |
| 调派完成图元清空 | 100% 得满分 | 每残留 1 个图元扣 0.5 分 |
| ID 业务前缀合规 | 100% 得满分 | 每发现 1 个无前缀 ID 扣 1 分 |

#### 2.2.5 架构合规（20 分）

基于五层架构调用链合规度。

```
架构合规得分 = 20 × 合规率
```

| 指标 | 满分条件 | 扣分规则 |
| ---- | -------- | -------- |
| UI 不直接调通用控制层 | 100% 阻断 | 每发现 1 处越层扣 4 分 |
| 业务控制层不调渲染层 API | 100% 阻断 | 每发现 1 处越层扣 4 分 |
| 协议层强约束 WGS84 | 100% 阻断 | 出现 1 次坐标污染扣 5 分 |
| Auto-Fit Padding 保留 | 100% 修正 | 每发现 1 次缺失扣 1 分 |
| 状态机迁移符合 08 定义 | 100% 阻断 | 每发现 1 次非法迁移扣 2 分 |

### 2.3 综合评分与等级

```
综合得分 = 渲染性能(25) + 业务响应(25) + 算路效率(15) + 资源回收(15) + 架构合规(20)
```

| 等级 | 分值 | 说明 |
| ---- | ---- | ---- |
| A 优秀 | ≥ 90 分 | 可发版，所有维度 ≥ 80% 满分 |
| B 良好 | 80 ~ 89 分 | 可发版，需关注低于 80% 的维度 |
| C 合格 | 70 ~ 79 分 | 条件发版，需整改低于 60% 的维度 |
| D 不合格 | < 70 分 | 禁止发版，必须整改 |

## 3. 检测工具与方法

| 维度 | 检测方法 | 工具 |
| ---- | -------- | ---- |
| 渲染性能 | 5 场景脚本化跑分 | Playwright + 浏览器 DevTools |
| 业务响应 | 关键操作打点 | `GIS_OPERATION` 通道 + Sentry |
| 算路效率 | 算路接口耗时监控 | 服务端日志 + 前端 APM |
| 资源回收 | 场景结束快照对比 | 自研 `LayerInspector` |
| 架构合规 | 静态扫描 + 运行时检查 | ESLint 自定义规则 + `ArchitectureGuard` |

#### 断言清单

1. 评分用于衡量 GIS 前端整体实现质量，非个人绩效；评分周期为每迭代/每发版。
2. 5 个核心场景帧率全部 ≥ 30fps 才可获得渲染性能满分，跟踪场景按节流 30fps + 事件驱动状态机实现。
3. 业务响应延迟硬约束：来电弹屏 ≤ 500ms、调派路径 ≤ 1s、状态机迁移 ≤ 200ms。
4. 资源回收通过自研 `LayerInspector` 检测场景结束后的图元残留，残留率必须为 0%。
5. 架构合规禁止 UI 直接调用通用控制层、业务控制层调用渲染层 API，违反每次扣 4 分。
