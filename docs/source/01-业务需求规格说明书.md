## 1. 产品概述

### 1.1 产品名称

GIS 前端（Geographic Information System Frontend）

### 1.2 产品愿景

打造消防接处警系统中**实时、准确、可靠**的地图指挥前端，实现"接处警业务 + 地图能力"深度融合的端到端可视化与控制链路，支撑"值守、来电、问询、调派、跟踪"五个核心场景下的高并发、高可用、零中断运行。

### 1.3 产品定位

以 **五层架构**（Service → Protocol → Calc → Ctrl → Render）为核心，承接后端业务事件，输出图形指令到 OpenLayers / ThreeJS 渲染层，是接处警业务的"地图控制中枢"。

### 1.4 目标用户

- **直辖市总队 / 支队**消防指挥中心的一线接警员与调度员。
- **非直辖市支队 / 大队**消防指挥中心的值班长、班长、运维与巡检人员。
- **主前端 Host**：与本前端（`gis-web`）双向通信的接处警主前端（警情列表、接处警表单等）。

### 1.5 业务目标

- 在 5 个核心场景中保证"业务事件 → 地图呈现"的端到端时延满足 SLA。
- 多中心、多场景、高并发下，地图状态不漂移、图元 ID 不冲突、临时资源能精准回收。
- 车辆跟踪、路径算路、警情上图等高频操作不阻塞主线程、达到稳态 ≥30fps。

## 2. 功能需求

### 2.1 值守（Duty）

- 进入值守场景时，加载默认中心点、默认缩放级别（15 级）。
- 批量加载辖区兴趣面、出入口、消防栓、道路等基础图层。
- 渲染当前可见警情分布（热力图或聚合点）。
- 提供缩放 / 平移 / 复位 / 指北 / 主题切换等基础工具。

### 2.2 来电弹屏（Incoming Call）

- 后端推送 `call.incoming` 事件后立即弹屏。
- 视野自动 fit 至 500m 圆，zoom 强制 18 级，留边 12%。
- 弹屏 UI 显示来电号码、地址、归属辖区、关联历史警情。
- 来电结束或转接后自动清除弹屏与图元。

### 2.3 问询研判（Inquiry）

- 进入问询后，视野聚焦微围栏（建筑 + 50m 缓冲）。
- 微围栏高亮（黄色描边、淡黄填充）。
- 查询围栏内兴趣面（AOI）、出入口、消防栓等资源。
- 命中 AOI 列表逐项展示，hover 显示建筑名称、楼层、风险等级。

### 2.4 图上调派（Dispatch）

- 多车路径并行计算（≤ 5 辆），单车算路 ≤ 1s。
- 推荐路径加粗高亮；远端站点（> ETA_MAX）半透明。
- 调派围栏四级联动：辖区 → 责任区 → 微型围栏 → 灾情点。
- 路径切换响应 ≤ 100ms；视野 fit 留边 12%。

### 2.5 跟踪到场（Tracking）

- 车辆 GPS 高频推送（≥ 2fps）后实时上图。
- 跟踪模式下视野自动 follow 当前车辆（允许用户拖动解除）。
- 微观视图（zoom ≥ 19）显示车辆细节（车号、状态、ETA）。
- 实时路径抽稀（≤ 200 点/批）≤ 100ms。

### 2.6 主前端协作

- 与主前端（Host）通过 postMessage 双向通信。
- 接收主前端的页面跳转、警情定位、图元联动等指令。
- 向上汇报当前 GIS 视野状态、要素拾取结果、用户操作事件。

### 2.7 配置与图元管理

- 5 个核心场景的临时图元按业务前缀（`call_`、`incident_`、`vehicle_`、`route_` 等）隔离与回收。
- 场景切换时通过 Pinia store 的 `reset()` 重置临时状态。
- 资源图层 ID 与 `docs/source/05-五层架构领域模型设计.md` 一致。

#### 断言清单

1、GIS 前端是"地图控制中枢"，不是单纯的地图展示组件；它必须承担业务事件消化、状态机维护、通用控制指令拼装。

2、五层架构（Service / Protocol / Calc / Ctrl / Render）是强约束，任何实现不得跨层调用、绕开 store 渲染、计算层持有 DOM/Map 引用。

3、WGS84 坐标系责任分工是硬约束：协议层与控制层强 WGS84；进入渲染层前由底座插件负责转换。

4、Auto-Fit 必须保留 10%~15% Padding，不得贴边；默认 paddingRatio = 0.12。

5、5 个核心场景（值守/来电/问询/调派/跟踪）的 AC 是验收硬基线；任何一档不达标禁止宣称完成。

6、所有业务图元 ID 必须加业务前缀（`marker_` / `polygon_` / `line_` / `cluster_`），命名必须出现在 05 资源图层 ID 清单中。

7、高频数据（GPS ≥2fps、轨迹批处理、抽稀）必须走 Web Worker + Transferable Objects，禁止 JSON 序列化传输。

8、协议层 DTO Schema（`docs/source/协议层DTO Schema.tsd`）必须与 `src/controller/core/protocol/*.ts` 100% 一致，CI 强制校验。
