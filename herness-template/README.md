## AI 读取策略

接到任务时按以下顺序读取：

1. **[00-SOP.md](00-SOP.md)** → **【强制第一站】** 工作规范、行为规则、质量门禁
2. **[04-迭代管理/_index.md](04-迭代管理/_index.md)** → 迭代总览表，找到当前周
3. **[04-迭代管理/{当前周}/周产物汇总.md](04-迭代管理/周产物汇总.md)** → 本周各角色产物
4. **[05-共享上下文/_index.md](05-共享上下文/_index.md)** → 当前状态摘要、阻塞项
5. **按需深入各域** → 通过 _index.md 导航到具体设计文档

## 文档"双轨制"

| 类型 | 含义 | 位置 | 示例 |
|------|------|------|------|
| **整体文档** | 持续积累，按模块组织 | `01~03,05/` | 架构设计、接口设计、测试策略 |
| **迭代文档** | 每周产出，按周管理 | `04-迭代管理/{YYYY-WXX}/` | 产物计划、产物汇总 |

**流转规则**：

```
每周开始：在 04-迭代管理/{周}/ 中填写产物计划
  ↓
每周执行：产物写入对应域目录（01~03）
  ↓
每周结束：迭代文件夹中记录产物链接（非文档本身）
  ↓
归档：迭代文件夹移入 _archive/
```

## 落地说明

- 本目录为通用模板：目录命名（如 `后端/前端`）与技术栈无关，可按项目实际调整
- 使用前请完成：更新 `05-共享上下文/技术栈速查.md`、`项目结构速查.md`、`核心概念术语.md`、`设计规范速查.md`
- 新增目录/文档时保持各域 `_index.md` 同步更新
