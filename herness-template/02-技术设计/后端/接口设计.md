## 6. API 设计原则

1. **向前兼容**：新增字段用 `optional`，不删除已有字段
2. **错误信息可读**：错误提示直接面向调用方，可展示
3. **分页统一**：所有列表查询使用统一分页参数
4. **金额精度**：金额一律用整数最小单位（如分），避免浮点精度
5. **枚举约束**：枚举字段声明可选值，前后端共享
6. **RESTful 倾向**：GET 查询、POST 创建/操作、PUT 更新、DELETE 删除
