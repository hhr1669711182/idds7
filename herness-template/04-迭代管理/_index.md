# 04-迭代管理

> **核心目录**：按周迭代管理各角色产出的产物。解决"只有域目录，无法衡量每周工作"的问题。

## 迭代总览表

| 迭代 | 起止日期 | 状态 | 产品设计产物 | 技术设计产物 | 测试产物 |
|------|---------|------|------------|------------|---------|
| | | | | | |

> 每开始一个新的迭代，在此表新增一行。

## 目录结构

```
04-迭代管理/
├── _index.md           # 你在这里（迭代总览 + 导航）
├── _templates/          # 迭代文档模板
├── YYYY-WXX/            # 每周迭代文件夹
│   ├── 产物计划.md       # 本周计划产出的产物清单
│   ├── 产品设计产物.md   # 产品经理产出的文档
│   ├── 技术设计产物.md   # 技术产出的文档（前端 + 后端）
│   ├── 测试产物.md       # 测试产出的用例、报告
│   └── 周产物汇总.md     # 本周全部产物汇总
└── _archive/            # 已完成的历史迭代归档
```

## AI 读取路径

1. 从上方的**迭代总览表**找到当前进行中的迭代
2. 进入对应的 `YYYY-WXX/` 文件夹
3. 读 `周产物汇总.md` 了解本周全部产出
4. 按需进入各域产物文件，找到对应文档链接

## 产物类型

产物 = 各角色在迭代中产出的文档、设计稿、代码方案等。产物通过**文档链接**关联到各域目录下的具体文档。

| 角色 | 产物类型示例 | 存放位置 |
|------|------------|---------|
| 产品经理 | PRD、原型、业务流程 | 01-产品设计/ |
| 前端开发 | 页面设计、组件设计、状态管理方案 | 02-技术设计/前端/ |
| 后端开发 | API设计、数据库设计、架构方案 | 02-技术设计/后端/ |
| 测试 | 测试用例、测试报告 | 03-测试/ |

> 产物文档本身写在各域目录下，迭代管理目录只记录**产物清单 + 链接**。

## 模板

新迭代开始时，复制 `_templates/` 中的模板到新迭代文件夹，填写产物计划。
