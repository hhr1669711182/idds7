> AI 接手任务时"第一口"就要读的关键信息，帮助 AI 快速理解项目全貌。

## 文件列表

| 文件 | 说明 | AI 何时读 |
|------|------|----------|
| [技术栈速查.md](./技术栈速查.md) | 前后端技术栈一览 | 首次了解项目 |

## AI 工作流

```
┌──────────────────────────────────────────────────────────┐
│  AI 接手任务                                              │
│  ↓                                                       │
│  1. 读 00-SOP.md                      【强制】工作 SOP    │
│  2. 读 README.md                      了解整体结构        │
│  3. 读 04-迭代管理/_index.md         找到当前迭代        │
│  4. 读 当前迭代/周产物汇总.md         本周产物            │
│  5. 读 05-共享上下文/当前状态摘要.md   项目当前状态       │
│  6. 读 05-共享上下文/核心概念术语.md   业务术语           │
│  7. 按需读 01/02/03 各域文档         获取详细设计        │
│  ↓                                                       │
│  开始研发工作                                             │
│  ↓                                                       │
│  任务完成 → 回写 00-SOP.md 工作日志留痕                   │
└──────────────────────────────────────────────────────────┘
```

## 维护责任

- **00-SOP.md**：AI 每次工作自动维护（留痕写入工作日志）
- **技术栈速查**：技术负责人维护，技术栈变更时更新
- **核心概念术语**：产品经理维护，新增业务概念时更新
- **当前状态摘要**：迭代负责人维护，每周迭代开始时更新
- **设计规范速查**：技术负责人维护，规范变更时更新
