# 项目结构速查

> 关键目录和文件位置
> 项目落地时替换为实际目录结构。

## 项目根目录

```
{项目名}/
├── {herness 目录}/       # ★ AI 工作框架（流程规范 + 设计文档 + 迭代管理）
├── {后端目录}/           # 后端服务
└── {前端目录}/           # 前端
```

## 后端关键路径

| 路径 | 说明 |
|------|------|
| {后端}/api/ | API 定义，代码生成输入 |
| {后端}/internal/handler/ | HTTP handler |
| {后端}/internal/logic/ | 业务逻辑 |
| {后端}/internal/types/ | 请求/响应类型 |
| {后端}/models/ | 数据模型 |
| {后端}/etc/ | 配置文件 |
| {后端}/docs/ | API 文档 |

## 前端关键路径

| 路径 | 说明 |
|------|------|
| {前端}/src/api/ | API 接口定义 |
| {前端}/src/views/ | 页面视图 |
| {前端}/src/components/ | 公共组件 |
| {前端}/src/stores/ | 状态管理 |
| {前端}/src/router/ | 路由配置 |
| {前端}/src/utils/ | 工具函数 |
