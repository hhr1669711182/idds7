## 4. Mock 说明

- **数据库**：使用内存 SQLite 或 testcontainers，确保测试隔离
- **消息队列**：Mock Producer，验证消息内容但不实际发送
- **缓存**：不涉及（{模块} 不依赖缓存）或 Mock Redis
