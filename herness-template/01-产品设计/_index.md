# 01-产品设计

## 目录结构

```
01-产品设计/
├── _index.md           # 你在这里
├── 已归档/              # 已上线产品文档（按业务模块归档）
├── 开发中/              # 未上线产品文档（含待评审、进行中、调研）
└── 需求文档模板.md
```

## 产品文档状态

| 状态 | 含义 |
|------|------|
| **已归档** | 已上线的全量产品文档，上线后下达归档指令 |
| **开发中** | 未上线的产品文档（含待评审、进行中、调研） |

## 设计原则

- 每个需求文档包含：业务上下文 → 业务对象 → 功能清单 → 页面信息架构 → 业务规则汇总
- 涉及多端时，标注是哪个端（如 Web 端、移动端）
